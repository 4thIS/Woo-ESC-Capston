# 경진대회 시연 가이드 (2026-11-19~20)

> 본선: 예체능관 3층 실내체육관, **발표 5분 + 질의응답 3분**, 작품 전시·현장 심사. 작품명 ESC(E-paper Share Class).
> 이 문서는 시연 순서·비상 절차·챙길 것을 한곳에 둔다. 비밀번호·토큰은 적지 않는다.

## 1. 구성

| 장비 | 현장 구성 | 확인 |
|---|---|---|
| ESP노드 2대 | E301-1(Good Display 패널), E803-1(Waveshare 패널). 배터리 완충, 3D 케이스 | 부팅 후 시각을 받아 화면이 그려졌는가 |
| 모뎀Pi | Raspberry Pi + Heltec 모뎀(USB). `modempi` 서비스 | 메인Pi 에 접속(관리자 웹 모뎀Pi 카드 초록 점) |
| 메인Pi | 서버·웹(Docker). 공개 주소 https://esc.ssenu.cloud | 관리자 웹 로그인 |
| 노트북 | 관리자 웹·학생 웹 시연, Tailscale(비상 접속) | 충전기 |
| 네트워크 | 현장 Wi-Fi 또는 **휴대폰·노트북 핫스팟** — 모뎀Pi·메인Pi 가 인터넷에 붙어야 서로 연결된다 | 모뎀Pi 시계가 인터넷 시간과 맞았는가(맞기 전엔 시각 방송을 하지 않는다) |

무선: 922.5 MHz, SF9·BW125, 14 dBm. 책상 거리(수 m)에서 수신 세기 −50~−80 dBm 이 정상.

## 2. 전날·당일 아침 점검

1. 노드 배터리 완충(완충 약 11~13 시간 — 전날 밤 5V 2A 충전기). 주황 LED 꺼짐 = 완충
2. 두 노드 펌웨어가 main 최신(과목명 32 B·연속 교시 한 줄, #141·#143)인지. 803 은 `PLATFORMIO_BUILD_FLAGS="-DNODE_ROOM=803" pio run -e terminal -t upload`
3. 803호 시간표 = 학교 2026-2 강좌 파일 기준 16교시(분반을 과목명 뒤에)
4. 모뎀Pi 를 켜고 1~2 분 뒤 **두 노드 화면이 그려졌는지** 확인(모뎀Pi 가 기동 직후 시각을 한 번 보낸다)
5. 관리자 웹 → 노드 상태: 두 노드 `synced`, 최근 응답 시각이 방금
6. 시연용 변경 하나를 미리 해 보고 되돌린다(아래 3절 시나리오 1)

## 3. 발표 5분 흐름

| 시간 | 내용 | 화면 |
|---|---|---|
| 0:00–0:40 | 문제: 종이 시간표는 휴강·보강·대관이 반영되지 않고, 바뀐 정보는 포털에만 있다. 강의실 이용률 38%, 공간 데이터 활용 47.6% | 판넬 |
| 0:40–1:30 | 해결: 배선 없이 문에 붙이는 전자잉크 단말 + 웹에서 바꾸면 LoRa 로 문 앞 화면 갱신. 메인Pi → 모뎀Pi → ESP노드 | 판넬 구성도, 실물 노드 |
| 1:30–3:30 | **실시간 시연**(시나리오 1, 남는 시간에 2) | 노트북 관리자 웹 + 노드 |
| 3:30–4:30 | 결과: 갱신 지연 50회 모두 30 초 안(중앙 4.5 초), 인터넷 34 분 끊겨도 복구 후 자동 전달, 노드 2대 | 판넬·노트북 |
| 4:30–5:00 | 확장: 회의실·스터디룸·실험실 안내판, 예약·사용 기록으로 공간 배정 근거 | 판넬 |

### 시나리오 1 — 휴강 처리(가장 확실)
1. 관리자 웹 → 강의실 → 공학관 803호 → 지금 진행 중인 교시를 휴강으로 바꾼다
2. "저장 → 약 5 초 뒤 노드가 받았다고 응답(노드 상태에 표시) → 8 초 뒤 화면을 다시 그리기 시작 → 약 18 초(803) / 27 초(301) 동안 3색 갱신"
3. 기다리는 동안: "전자잉크는 화면이 바뀔 때만 전력을 써서 배터리로 오래 간다. 지금 이 깜빡임이 3색 리프레시"
4. 끝나면 되돌린다

### 시나리오 2 — 학생 예약 → 대여중
학생 웹에서 빈 강의실 예약 신청 → 관리자 웹 승인 → 노드가 `대여중`(예약자 '학생')

## 4. 예상 질문

| 질문 | 답 |
|---|---|
| 왜 Wi-Fi 가 아니라 LoRa? | Wi-Fi 송신 피크 약 150 mA 라 배터리로 못 버티고, 교내 AP 사각지대·인증에 묶인다. LoRa 는 건물당 중계기 1대, 저전력 |
| 배터리는 얼마나? | 설계 목표 하루 15 mAh 이하·5,000 mAh 로 280일 이상(딥슬립·무선 웨이크). 오늘 시연 펌웨어는 늘 깨어 있는 모드라 약 4일. 절전 모드 실측은 12월 |
| 화면이 바뀌는 데 왜 30~40 초? | 전달은 약 5 초. 나머지는 3색 전자잉크 리프레시(18~27 초)와 연속 변경을 모으는 8 초 대기 |
| 신호가 끊기면? | 응답이 없으면 5·20·60 초 간격 재전송, 버전이 어긋나면 서버가 그 강의실 전체를 다시 보낸다. 서버가 멈춰도 노드는 저장한 시간표와 자기 시계로 계속 맞는 화면을 보인다 |
| 인터넷이 끊기면? | 메인Pi·모뎀Pi 양쪽 작업 저장소에 남았다가 다시 붙으면 자동 전달(11/11 실측: 34 분 차단, 복구 28 초 뒤 재접속, 10건 36 초 안 전달) |
| 거리는? | 시연 SF9 기준 실내 수십 m. 확산 계수(SF)를 올리면 더 멀리 가지만 전송이 느려지고, 지금은 프로토콜 상수라 바꾸면 모뎀·노드를 함께 다시 굽는다. 출력은 법정 14 dBm 이하. 먼 강의실은 모뎀Pi 를 건물에 하나 더 둔다 |
| 전파법은? | KR920(917~923.5 MHz) 비면허, 출력 14 dBm, 송신 전 채널 확인(LBT) |
| 비용은? | 단말 1대 부품 약 16~17만 원(보드 4~5.5만·7.5" 3색 패널 약 8.8만·어댑터·배터리·안테나, 부가세 포함 구매가), 모뎀Pi 는 건물당 1대 |
| 시간표 입력은? | 관리자 웹 직접 입력 또는 CSV. 학교 강좌 파일에서 강의실별로 뽑아 넣었다(분반을 과목명 뒤에) |
| 쉬는시간은 어떻게 아나? | 같은 날 수업 사이 틈이 15분 이하이면 쉬는시간 — 노드가 저장한 시간표와 시계로 스스로 판단 |

## 5. 비상 절차

| 증상 | 조치 |
|---|---|
| 노드 화면이 안 바뀌는데 관리자 웹에는 `acked` | 노드가 재부팅돼 시계가 빈 상태. FW 4(#155)부터는 노드가 부팅 직후 STATUS 로 시각을 요청해 **보통 10 초 안에 스스로 회복**한다. 1 분 넘게 그대로면 **모뎀Pi 서비스 재시작**(`sudo systemctl restart modempi`) → 기동 직후 시각 방송 → 8 초 뒤 그림 |
| 관리자 웹에서 `queued` 가 안 줄어듦 | 모뎀Pi 연결 끊김. 모뎀Pi 네트워크·전원 확인 → 다시 붙으면 쌓인 것 자동 전달. 급하면 서비스 재시작 |
| 모뎀Pi 가 시각을 안 보냄(로그 "NTP 미동기") | 모뎀Pi 가 인터넷 시간을 아직 못 받음. 인터넷 연결 확인 후 1~2 분 대기(1 분마다 다시 봄) |
| 노드 화면이 1~2 초 만에 끝나고 안 바뀜 | 패널 배선(BUSY·전원) 또는 FPC. 예비 노드로 교체 |
| 노드 무응답(`no_ack` → 재시도) | 안테나 체결·전원 확인, 노드 재부팅(RST) — 시각은 노드가 스스로 요청한다(FW 4) |
| 배터리를 꽂으면 USB 로도 안 켜짐 | 배터리 손상(내부 단락·과방전)이 3.3 V 를 끌어내림(11/17 E803 실례). 배터리를 빼고 예비로 교체, 손상 배터리는 따뜻하거나 부풀었는지 확인 후 폐기 |
| 특정 강의실만 데이터가 이상함 | 관리자 웹 노드 상태 → **재전송**(그 방 시간표·예약·시험 전부 다시 보냄) |
| 인터넷 전부 불가 | 노트북 핫스팟에 모뎀Pi·메인Pi 를 붙인다. 공개 주소가 안 되면 메인Pi 를 노트북과 같은 망에서 IP 로 접속 |

시연 중에는 **main 머지를 하지 않는다** — 메인Pi 가 main 이 바뀌면 2 분 안에 재배포하며 서버가 잠깐 재시작된다.

## 6. 챙길 것

- [ ] ESP노드 2대(케이스 조립, 배터리 완충) + 예비 Heltec 보드 1, 예비 배터리 1
- [ ] 모뎀Pi + Heltec 모뎀 + 모뎀 안테나 + Pi 전원 어댑터
- [ ] 메인Pi(현장 운영 시) + 전원 어댑터 / 또는 원래 자리에서 운영
- [ ] USB-C 데이터 케이블 2개 이상(충전 전용 케이블 주의), 5V 2A 충전기, 멀티탭
- [ ] 노트북 + 충전기, 휴대폰 핫스팟
- [ ] 자석·절연 테이프(문·판넬 부착용), 예비 점퍼선
- [ ] 판넬·작품보고서 출력물
