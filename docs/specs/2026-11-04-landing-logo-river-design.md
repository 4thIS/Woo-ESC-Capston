# 대학 로고 강 — 메인 페이지 물리 인터랙션 · 설계 (spec)

- 생성일시: 2026-11-04
- 수정일시: 2026-11-04
- 시안: [캔버스](https://claude.ai/artifact/DDAuxgcbhPELj65YHEvd5W) `D-Landing` · `D-Login` · `D-Phone` (밝은 바탕)
- 화면 스펙: `docs/design/screens/landing.md` 「히어로」 · `docs/design/screens/auth.md` 「넓은 폭」
- 담당: wj 가 스펙과 구현을 전담한다(팀장 승인 전제, 평소 mh → wj 순서의 예외). 이 작업에 한정한다.

## 0. 배경 · 위치

메인 페이지는 첫인상을 줄 그림이 없고, 경진대회(11/19~20)에서 사람들이 만져 볼 거리도 없다. 뒤 배경에 **각 대학 로고가 크기 제각각으로 오른쪽에서 왼쪽으로 흐르게** 하고, PC 메인 페이지에서는 그 흐름을 **강물처럼 손으로 건드릴 수 있게** 한다.

- 잡고 있으면 그 자리에 머물고, 다른 로고는 부딪혀 비켜 간다.
- 던지거나 놓으면 슉 날아가 다른 로고와 부딪히고, 스윽 느려지며 다시 흐름을 탄다.

## 1. 목표 · 비목표

### 목표

1. 메인 페이지 히어로와 인증 화면 왼쪽(폰은 로그인 위 띠)을 시안대로 바꾸고 로고 흐름을 넣는다.
2. **PC 메인 페이지에서만** 로고를 잡고 던질 수 있다. 나머지 화면은 같은 그림이 흐르기만 한다.
3. 로고는 SVG 를 쓰고, 어쩔 수 없을 때만 배경 없는 PNG 를 쓴다. 크기는 인지도 순위를 따르되 차이가 크지 않다.
4. 로고가 글자·버튼의 읽기와 누르기를 방해하지 않는다.

### 비목표

- 로고 회전(부딪혀도 똑바로 선다 — 글자 로고를 읽을 수 있어야 한다).
- 폰 · 태블릿 · 터치 화면의 잡기. 로그인 화면의 잡기.
- 키보드로 로고 움직이기(장식이라 스크린리더와 키보드에 드러내지 않는다).
- 어두운 바탕(시안 `E-*`)과 시안 A~C 안.
- 히어로 아래 구역 변경(기능 카드 · 시작하는 방법은 그대로. 바닥글은 §3 고지 한 줄만 더한다).

## 2. 데이터 · 계약

- `lora_proto/`, DB, 서버 응답: **변경 없음.** 로고는 서버를 부르지 않는 정적 파일이다.

### 로고 파일 규칙

| 항목 | 규칙 |
|---|---|
| 위치 | `web/src/assets/logos/<slug>.svg`(또는 `.png`), 목록 `web/src/assets/logos/logos.json` |
| 형식 | **SVG 우선.** SVG 를 못 구하면 **배경이 투명한 PNG**(알파 채널 필수, 긴 변 800px 이하, 가능하면 400px 이상. 연세대는 공식 페이지의 177px 파일뿐이라 예외). JPG 와 배경 있는 그림은 쓰지 않는다. PNG 를 벡터로 자동 변환하지 않는다(마크가 변형된다) |
| 크기 | SVG 40 KB · PNG 120 KB 이하, 합계 800 KB 이하. 넘으면 내용을 바꾸지 않는 최적화(`svgo`, 커밋 전 1회 실행, 의존성 추가 없음) |
| 변환 | 공식 AI 파일을 원본 그대로 투명 PNG 로 렌더링하는 것은 허용한다(동국대). 그림을 다시 그리거나 배경을 직접 지우는 것은 금지 |
| 쓰는 법 | `<img>` 로만 넣는다(SVG 안 스크립트가 돌지 않는다). 외부 주소 직접 연결 금지 — 메인Pi 가 오프라인일 수 있다 |
| 기록 | `logos.json` 각 항목에 `slug` · `name` · `rank` · `file`(파일 이름) · `source`(내려받은 주소) · `license` · `aspect`(가로÷세로) |

### 크기

로고마다 면적이 같은 "지름" `D` 를 먼저 정하고, 가로세로 비율을 지켜 상자를 만든다. 가로로 긴 로고가 혼자 커 보이지 않게 하려는 것이다.

```
D(i) = 170 − (i ÷ (N−1)) × 60    (i = 목록 안 순서 0부터, N = 로고 수) → 170 ~ 110 px, 최대 1.55배
w = D × √aspect,  h = D ÷ √aspect
```

- `aspect` 가 4를 넘는 로고는 쓰지 않는다(위아래로 너무 얇아 안 읽힌다). 같은 대학의 다른 파일을 찾는다.
- 화면별 배율 `k`: PC 메인 1, 인증 왼쪽 0.72, 폰 · 태블릿 메인 0.56, 폰 로그인 띠 0.3.

## 3. 제약

### 로고 사용 — 공개 전 확인 🔴

대학 로고는 대부분 등록 상표이고, 연세대·서울대 등은 공식 페이지에서 사용을 제한한다. 또 메인 페이지에 올리면 **그 대학이 이 서비스를 쓰거나 제휴한 것처럼 보일 수 있다.** 법적 판단은 이 문서가 하지 않는다.

- 공개 사이트 반영 전에 팀장(cw)이 사용 범위를 확인한다. `main` 머지가 곧 운영 반영이므로 **코드 PR 머지 전에** 끝낸다.
- 바닥글에 고지 한 줄을 둔다: `표시된 로고는 각 대학의 상표이며, 제휴나 도입을 뜻하지 않습니다.` (wj 판단)
- `logos.json` 에서 항목을 빼면 로고가 사라지도록 해 언제든 바로 내릴 수 있게 한다.

### 어디서 물리가 켜지나

아래 **셋 다** 맞을 때만 켠다. 조건이 바뀌면(창 크기 등) 바로 다른 모드로 다시 그린다.

| 조건 | 값 |
|---|---|
| 화면 | 메인 페이지 히어로 |
| 입력·폭 | `(min-width: 1024px) and (hover: hover) and (pointer: fine)` |
| 움직임 설정 | `prefers-reduced-motion: reduce` 가 아님 |

그 밖에는 CSS 애니메이션으로 흐르기만 한다. 움직임 줄이기 설정이면 멈춘 그림이다(`base.css` 전역 규칙이 이미 끈다).

### 글자 · 버튼 보호

- 글자 쪽으로 갈수록 바탕색으로 덮는다. 글자 칸 오른쪽 끝까지 완전히 덮고 그 뒤 280px 동안 옅어진다. **가운데 정렬된 본문 틀 기준으로 잰다** — 넓은 모니터에서도 글자 위치와 맞는다.
- 덮인 곳의 로고는 잡히지 않는다. 안 보이는 것이 잡히면 안 된다.
- 링크 · 버튼 · 글자에서 시작한 누름은 잡기가 아니다(글자 선택과 클릭이 그대로 된다).
- 잡은 로고도 덮개 아래에 있다. 글자 위로 올라오지 않는다.

### 멈춤 (WCAG 2.2.2)

- PC 메인 히어로 오른쪽 아래에 `멈춤` / `재생` 버튼. 멈추면 전부 그 자리에 서고 잡을 수 없다. 저장하지 않는다.
- 다른 화면은 시안에 버튼이 없어 두지 않는다. 움직임 줄이기 설정으로 멈출 수 있다. (wj 판단 — §9)

### 성능

- 새 의존성 없음. 물리 엔진 라이브러리를 쓰지 않는다 — 회전 없는 로고 20개와 흐름 힘은 직접 짜는 쪽이 짧고, `matter-js`(약 80 KB)의 강체 회전은 쓸 곳이 없다.
- 히어로가 화면 밖이거나 탭이 숨겨지면 계산을 멈춘다.
- 매 프레임 Vue 를 거치지 않고 `transform` 만 바꾼다.

## 4. 동작

### 세계

- 폭 `W = max(2000, screen.width + 400)`, 높이 = 히어로 720px. 좌우는 이어져 있다 — 왼쪽 밖으로 나간 로고는 오른쪽 밖에서 다시 들어온다. 이어지는 곳은 언제나 화면 밖이다.
- 위아래는 벽이다. 부딪히면 튕긴다.
- 처음 자리는 황금비 수열로 고르게 흩고 겹침을 풀어 정한다. 크기 순서가 왼쪽부터 줄지어 보이지 않게 섞는다. 매번 같은 결과가 나온다(무작위 아님).

### 충돌 모양

회전하지 않는 **가로 캡슐**(양끝이 둥근 막대)이다. 동그란 로고는 길이 0인 캡슐, 즉 원이다.

```
반지름 r = min(w, h) ÷ 2,  막대 반길이 s = (w − h) ÷ 2 (w ≤ h 면 0)
세로로 긴 로고는 r = w ÷ 2 로 잡아 약간 겹칠 수 있다
```

### 한 프레임에 일어나는 일 (1/60 초 고정 스텝)

1. 잡히지 않은 로고의 속도가 흐름 속도로 돌아간다 — **스윽**.
2. 세로로는 자기 줄(`laneY`)로 약하게 돌아간다. 없으면 시간이 지나며 한쪽에 몰린다. 잡힌 로고에 닿으면 줄 자체를 비켜 옮겨 그 옆으로 지나가고(없으면 뒤에 줄지어 멈춘다), 지나간 뒤 원래 줄(`homeY`)로 천천히 돌아온다.
3. 잡힌 로고는 포인터를 짧은 지연으로 따라간다. 그 움직임이 곧 속도라 다른 로고를 밀친다.
4. 캡슐끼리 겹침을 풀고 튕긴다 — 질량은 면적에 비례, 잡힌 로고는 무한대(다른 로고만 밀려난다).
5. 벽 처리, 좌우 잇기, `transform` 반영.

그리기에서만 살짝 위아래로 뜨고 커졌다 작아진다(몽글몽글). 잡혀 있거나 빠르게 날아가는 동안은 사라지고, 흐름을 되찾으면 서서히 돌아온다.

### 잡기 · 던지기

| 사용자 행동 | 결과 |
|---|---|
| 로고 위에 올림 | 커서 `grab` |
| 눌러 잡음 | 커서 `grabbing`, 누른 지점을 유지한 채 따라옴. 잡힌 로고는 멈추고 다른 로고가 부딪혀 비켜 간다 |
| 움직이지 않고 놓음 | 속도 0에서 다시 흐름을 탄다 |
| 빠르게 움직이다 놓음 | 마지막 100 ms 의 포인터 속도로 날아간다(상한 있음). 부딪히고 느려져 흐름으로 돌아간다 |
| 잡은 채 히어로 밖으로 | 로고는 히어로 안에 머문다. 어디서 놓아도 놓은 것으로 친다 |
| 창 전환 · `pointercancel` | 속도 0으로 놓는다 |

- 겹쳐 있으면 가장 위(가장 작은) 로고가 잡힌다.
- 여러 로고를 동시에 잡지 않는다(마우스 하나).

## 6. 무회귀 · 롤아웃

- 메인 페이지에서 서버를 부르지 않는다는 규칙은 그대로다. 로고는 그림이라 본문 글자로 학교 이름이 나오지 않는다.

## 8. 성공 기준

- PC Chrome 에서 로고를 잡으면 멈춰 있고, 던지면 날아가 다른 로고를 밀치며, 5초 안에 흐름 속도로 돌아온다.
- 폭 390 · 768 과 터치 화면, 로그인 화면에서는 잡히지 않고 흐르기만 한다.
- `prefers-reduced-motion` 에서 움직이지 않는다.
- 글자 · 링크 · 버튼을 평소처럼 선택하고 누를 수 있다. 390 · 768 · 1280 · 2560 폭에서 가로 스크롤이 없다.
- 1시간 켜 둬도 로고가 한쪽에 몰리거나 서로 겹쳐 굳지 않는다(가상 시간 테스트).
- 로고 파일 합계 800 KB 이하. 새 의존성 없음. Vitest · 린트 · 타입 검사 · E2E 통과.

## 9. 열린 결정

1. **로고 사용 범위** — cw 확인 전에는 코드 PR 을 머지하지 않는다(§3).
2. **연세대 파일** — 공개 SVG 와 투명 PNG 가 모두 없으면 4위가 빠진다. 이 경우 사용자에게 알린다.
3. **멈춤 버튼 범위** — 지금은 PC 메인에만 있다. 접근성을 더 맞추려면 인증 화면과 폰에도 두어야 한다. 시안을 바꾸는 일이라 지금은 두지 않는다.
4. **조절값** — §4 값은 처음 값이다. 구현 뒤 사용자가 만져 보고 정한다.
