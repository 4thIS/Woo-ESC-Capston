# 단말 e-Paper 화면 (시안: https://claude.ai/artifact/EZJJuZyJysKM2pQVE4rAdh)

> 구현 담당: **dh** (`firmware/src/terminal/render*`, `firmware/src/fonts/`). 이 문서가 원본, 렌더 코드는 구현이다.
> 근거: `2026-09-09-roadmap-design.md` **§4.1 계약 ④ `RenderModel`** (이 화면의 유일한 입력) · `2026-09-16-s3-render-design.md` §2.1(`today[24]` 산정) · `2026-09-09-lora-v2-wor-design.md` §5.3(레이아웃 표)·§6.9(렌더 자산)

## 목적

강의실 문 앞에서 지나가며 3초 안에 **"지금 이 방을 쓸 수 있나"** 에 답하고, 이어서 **"오늘 이 방이 어떻게 쓰이나"** 를 보여준다. 읽는 거리 1~3 m, 복도 조명, 정지 화면.

렌더는 `RenderModel` 밖의 것을 읽지 않는다(로드맵 §4.1). 이 문서의 모든 화면 요소는 그 구조체의 필드이고, 구조체에 없는 값은 화면에 두지 않았다 — 뺀 항목과 이유는 아래 "계약에 없어서 뺀 것"에 적었다.

## 캔버스

| 항목 | 값 |
|---|---|
| 해상도 | 800 × 480 px |
| 패널 | Waveshare 7.5" (B) 흑/백/적, UC8179 (v2 §1.1) |
| 화소 밀도 | 약 124 ppi → 1 px ≈ 0.20 mm |
| 회전 | 가로(landscape). FPC는 좌측 |

회색 계조·투명도·안티에일리어싱이 없다. 위계는 **면적 · 굵기 · 반전** 세 가지로만 만든다.

## 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `color.ink` | `#000000` | 글자 · 선 · 반전면(푸터 · 현재 행 · 칩) |
| `color.paper` | `#FFFFFF` | 화면 바탕 · 반전면 위의 글자 |
| `color.signal` | 패널 적색 (RED 채널) | 상태 띠 바탕 — 사용중 4종에서만 |

- 적색은 **상태 띠 한 곳에만** 쓴다. 글자·선·아이콘에 적색을 쓰지 않는다.
  - 왜: 3색 패널의 적색 화소는 흑색보다 가장자리가 뭉개져 작은 글자가 흐려진다. 면으로 깔고 흰 글자를 뚫는 편이 복도 끝에서 훨씬 잘 읽힌다.
- 회색이 없으므로 **강조 수단은 반전(흑 채움 + 흰 글자) 하나뿐**이다. 한 화면에서 반전은 **상태 띠 · 오늘 목록의 현재 행 · 푸터** 세 곳만 쓴다. 넷째 반전을 늘리면 위계가 무너진다.
- 모든 선은 **단색 흑 1 px 또는 2 px**. 회색 선 · 점선 · 그림자 금지.
- 시안은 실물 느낌을 위해 `#111111` / `#ECEBE5` / `#C8102E`로 렌더했다. **구현 값은 위 표의 순흑·순백·패널 적색이다.**

## 타입 — 6단계 고정

| px | weight | 용도 |
|---|---|---|
| 78 | 900 | 상태명 |
| 62 | 900 | 다음 수업 시작 시각 · `NEW-xxxx` · 설정 대기 제목 |
| 32 | 900 | 호수 |
| 28 | 700 | 과목명 · 담당교수 · 강의시간 값 |
| 20 | 400 | 헤더 요일·시각 · 상태 보조 문구 · 라벨 · 목록 과목 |
| 16 | 400 | 푸터 · 목록 시각 · "호" · 칩류(700) |

- 이 6단계 밖의 크기를 새로 만들지 않는다. 자리가 부족하면 단계를 낮추지 말고 **문구를 줄인다.**
- 최소 16 px ≈ 3.3 mm. 상태명 78 px ≈ 16 mm로 3 m에서도 읽힌다.
- 자간: 78·62·32 px는 -0.03~-0.04 em, 28 px는 -0.02 em, 칩류는 +0.04 em.
- 본문 굵기는 **400(Regular)** 이다. 한글 본문 폰트 나눔고딕은 400 · 700 · 800만 있고 500(Medium)이 없다 — v1도 이 자리에 Regular를 썼다(이슈 #34).

## 영역별 규격

### 헤더

- 좌: 호수 `301` (32/900) + `호` (16/400), 간격 10, 베이스라인 정렬
- 우: `화요일` (20/400) — `weekday`만
- **현재 시각을 그리지 않는다.** e-Paper는 상태가 바뀔 때만 다시 그리므로 화면에 박힌 시각은 몇 시간째 멈춰 있을 수 있다 — 틀린 정보가 된다. 요일은 하루 안에서 상하지 않으므로 남긴다.
- 월·일 숫자는 `RenderModel`에 없다. 건물 이름도 쓰지 않는다(`bld`는 코드 문자 하나).

### 상태 띠

- 상태명 (78/900, line-height 0.98) + 보조 문구 (20/400), 간격 8, 세로 중앙
- RED 상태: 바탕 `color.signal`, 글자 `color.paper`
- BLACK 상태: 바탕 `color.paper`, 글자 `color.ink`, 하단 2 px 선

보조 문구는 상태마다 한 줄 고정:

| 상태 | 보조 문구 | 출처 |
|---|---|---|
| 수업중 · 시험중 · 특강 · 대여중 | `15:00에 끝납니다` | `cur.eH:eM` |
| 쉬는시간 | `14:00 수업 재개` | `next.sH:sM` |
| 빈강의실 | **없음** — 아래 정보 영역이 같은 내용을 더 크게 말한다 | — |
| 휴강 | `오늘 휴강입니다` | — |

### 정보 — 형태 A (현재 슬롯 있음 · `cur.flags` bit0 = 1)

3행 고정. 라벨열 104 px (x 24–128), 간격 18, 값 x 146부터 (폭 330).

| 행 | 라벨 (20/400) | 값 (28/700) |
|---|---|---|
| 1 | 과목명 | `cur.subj` |
| 2 | 담당교수 | `cur.prof` |
| 3 | 강의시간 | `cur.sH:sM – cur.eH:eM` |

`cur.flags` bit1(변경 배지)이 서면 1행 값 뒤에 `변경` 칩(16/700, 흑 채움)을 붙인다.

### 정보 — 형태 B (현재 슬롯 없음 · 빈강의실)

- `다음 수업` (20/400) + 아래 한 줄, 간격 10, 세로 중앙
- 아래 줄: 시작 시각 `13:00` (62/900) + 과목명 `캡스톤디자인` (28/700), 베이스라인 정렬, 간격 16
- **잔여 시간("40분")을 쓰지 않는다.** 렌더 시점에 굳어버려 40분이 지나도 계속 "40분"이라고 말한다. 시작 시각과 과목명은 굳지 않는다.
- `next.flags` bit0=0이면 `오늘 일정 없음` (28/700) 한 줄로 대체

### 오늘 목록 — 표시 상한 **N = 9**

`nToday` + `today[24]`를 그린다. 교수 이름은 이 배열에 없다(시각 · 과목 · `type`만).

**왜 9인가** — 컬럼 높이 388에서 상하 패딩 32와 "오늘" 칩 32(칩 22 + 간격 10)를 빼면 324 px, 행 높이 36으로 정확히 9행이다.

**왜 이전/다음 칸을 두지 않나** — `prev`·`next`는 `today[]`의 부분집합이다. 목록에서 현재 행을 반전하면 "지금 몇 번째인지"가 그 안에서 읽히므로 같은 값을 두 번 그릴 이유가 없다. (`next`는 상태 보조 문구와 형태 B에만 쓴다.)

**창 규칙**

- `nToday ≤ 9` → 전부 그린다.
- `nToday > 9` → 현재 항목(없으면 다음 예정 항목)이 항상 보이도록 `start = clamp(curIdx − 1, 0, nToday − 9)`부터 9행.
- 잘린 쪽이 있으면 그 끝 행을 `↑ n개 더` / `↓ n개 더` (16/400)로 대체한다. 양쪽 다 잘리면 실제 일정은 7행만 보인다.
- `nToday = 0`이면 칩 아래에 `오늘 일정 없음` (20/400) 한 줄.

**행 구성** (높이 36, 좌우 패딩 18 → 내부 264)

| 요소 | 폭 | 타입 |
|---|---|---|
| 시작 시각 `09:00` | 46 | 16/400 |
| (간격) | 8 | |
| 과목 `캡스톤디자인` | 유동 | 20/400 |
| type 약어 | 우측 정렬 | 16/700 |

- `type` 약어: 1 수업 → **생략**, 2 시험 → `시험`, 3 휴강 → `휴강`, 5 특강 → `특강`, 6 대여 → `대여`. (4 빈강의실은 `today[]`에 들어오지 않는다.)
- **현재 진행 행**은 컬럼 폭 전체(x 500–800) 반전 + 과목 굵기 700.
- **지난 행은 흐리게 하지 않는다** — 회색이 없다. 각 행의 시각을 보고 읽는 사람이 판단한다.

### 푸터

흑색 바탕, 흰 글자 16/400. 좌측 정렬 한 줄:

| 내용 | 예 |
|---|---|
| 건물 · 호수 · 유닛 | `E · 301 · U1` |

- `bld`는 `char`(ASCII 문자)다 — `'E' 'A' 'S' 'M'`을 그대로 쓴다.
- 설치·점검 때 "이 단말이 어느 방으로 설정돼 있나"를 확인하는 용도다. 그 밖의 운영 값은 올리지 않는다.

### 화면에 두지 않은 것

| 뺀 것 | 이유 · 대안 |
|---|---|
| **현재 시각 `nowStr`** | e-Paper는 상태가 바뀔 때만 다시 그린다. 화면에 박힌 시각은 몇 시간째 멈춰 있을 수 있어 **틀린 정보가 된다.** 잔여 시간도 같은 이유로 쓰지 않는다 |
| **배터리 전압** | 계약에는 `battMv`가 있으나 **일부러 쓰지 않는다.** 문 앞에서 볼 값이 아니라 운영 지표다 — STATUS 업링크로 대시보드에 올라가고 `LOW_BATT`(< 3.5 V) 판정도 서버가 한다(v2 §3.3·§12). 학생에게는 의미가 없고 관리자는 대시보드를 본다 |
| 버전 `S/R/E` · `fw` | `RenderModel`에 없다. 동기 확인은 STATUS 업링크 → 대시보드로 충분하다 |
| `CLOCK_STALE` / 시각 미동기 | STATUS flags는 업링크 전용. 렌더는 모른다 |
| 시험기간 날짜 | `exams[]`는 상태 판단(cw) 쪽 데이터. 시험중 보조 문구를 `cur.eH:eM` 기반으로 바꿨다 |
| 월 · 일 날짜 | `weekday`만 있다 → 미결 1 |
| `rssiLast` · `snrLast` · `uptime_h` | 애초에 문 앞에서 볼 값이 아니다 (v2 §3.3, STATUS 업링크) |

## 문자열 한계

- 과목 **20 B**(UTF-8, 한글 6자) · 교수 **12 B**(한글 4자). v2 §5.1 고정 버퍼 그대로이며 codec이 초과를 `FrameError`로 막는다.
- 정보 행: 28 px × 한글 6자 ≈ 168 px, 값 영역 330 px 안. 목록 행: 20 px × 6자 = 120 px, 과목 영역 약 164 px 안.
- **줄바꿈 · 말줄임 처리를 설계하지 않는다.** 렌더 계층은 자르지 않는다(S3 spec §3).

## 미결

1. **월 · 일 날짜 표기** — 필요하다고 판단되면 `RenderModel`에 `dateStr[6]` 추가를 cw에 요청한다. 없으면 요일만으로 간다(현재 안).
2. **layout 8의 `NEW-xxxx`** — MAC 하위 2 B를 담을 필드가 `RenderModel`에 없다. `newTag[9]` 추가 요청이 필요하다. cw-11(계약 동결)에서 함께 결정.
3. **28 px Bold 한글 자산** — 플래시 여유(앱 3 MB, v2 §6.9)를 보고 dh가 판단한다. 어려우면 정보 행을 20 px로 내리고 그만큼 상태 띠를 키운다. 그 경우 타입 단계에서 28을 뺀다.
4. **유닛 2개 강의실** — 같은 방의 두 단말이 같은 화면을 그린다. 문별 구분이 필요하면 헤더에 유닛 표기를 올린다.
