# 단말 e-Paper 화면 (시안: https://claude.ai/artifact/EZJJuZyJysKM2pQVE4rAdh)

> 구현 담당: **dh** (`firmware/src/terminal/render*`, `firmware/src/fonts/`). 이 문서가 원본, 렌더 코드는 구현이다.
> 근거 스펙: `docs/specs/2026-09-09-lora-v2-wor-design.md` — §3.3 페이로드 · §5.1 저장 · §5.2 시계 · §5.3 상태 판단 · §5.4 `nextChangeAt` · §6.9 렌더링

## 목적

강의실 문 앞에서 지나가며 3초 안에 **"지금 이 방을 쓸 수 있나"** 에 답한다. 읽는 거리 1~3 m, 복도 조명, 정지 화면.

화면에 올리는 값은 전부 단말이 실제로 들고 있는 것이다. 서버에만 있는 값은 쓰지 않는다 — 단말은 서버가 죽어도 자기 시계·자기 데이터로 옳은 화면을 유지해야 하기 때문이다(스펙 §0-3 fail-operational).

## 캔버스

| 항목 | 값 |
|---|---|
| 해상도 | 800 × 480 px |
| 패널 | Waveshare 7.5" (B) 흑/백/적, UC8179 (스펙 §1.1) |
| 화소 밀도 | 약 124 ppi → 1 px ≈ 0.20 mm |
| 회전 | 가로(landscape). FPC는 좌측 |

회색 계조·투명도·안티에일리어싱이 없다. 위계는 **면적 · 굵기 · 반전** 세 가지로만 만든다.

## 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `color.ink` | `#000000` | 글자 · 선 · 푸터 바탕 · 태그 칩 바탕 |
| `color.paper` | `#FFFFFF` | 화면 바탕 · 적색 면 위의 글자 · 푸터 글자 |
| `color.signal` | 패널 적색 (RED 채널) | 상태 띠 바탕 — 사용중 4종에서만 |

- 적색은 **상태 띠 한 곳에만** 쓴다. 글자·선·아이콘에 적색을 쓰지 않는다.
  - 왜: 3색 패널의 적색 화소는 흑색보다 가장자리가 뭉개져 작은 글자가 흐려진다. 면으로 깔고 흰 글자를 뚫는 편이 복도 끝에서 훨씬 잘 읽힌다.
- 모든 선은 **단색 흑 1 px 또는 2 px**. 회색 선·점선·그림자 금지.
- 시안은 실물 느낌을 위해 `#111111` / `#ECEBE5` / `#C8102E`로 렌더했다. **구현 값은 위 표의 순흑·순백·패널 적색이다.**

## 타입 — 7단계 고정

| px | weight | 용도 |
|---|---|---|
| 78 | 900 | 상태명 |
| 62 | 900 | 잔여 시간 · `NEW-xxxx` · 설정 대기 제목 |
| 32 | 900 | 호수 |
| 28 | 700 | 과목명 · 담당교수 · 강의시간 값 |
| 24 | 700 | 이전·다음 시각 |
| 20 | 500 | 날짜·시각 · 상태 보조 문구 · 라벨 · 이전·다음 과목 |
| 16 | 500 | 푸터 · 이전·다음 교수 · "호" · 태그 칩(700) |

- 이 7단계 밖의 크기를 새로 만들지 않는다. 자리가 부족하면 단계를 낮추지 말고 **문구를 줄인다.**
- 최소 16 px ≈ 3.3 mm. 상태명 78 px ≈ 16 mm로 3 m에서도 읽힌다.
- 자간: 78·62·32 px는 -0.03~-0.04 em, 28·24 px는 -0.01~-0.02 em, 태그 칩은 +0.04 em.

## 영역별 규격

### 헤더

- 좌: 호수 `301` (32/900) + `호` (16/500), 간격 10, 베이스라인 정렬
- 우: `09.16 화 · 13:42` (20/500)
- 건물 이름은 쓰지 않는다 — 단말은 `bld` u8 코드만 들고 있고 이름 문자열이 없다(§5.1). 건물·유닛은 푸터로 내린다.

### 상태 띠

- 상태명 (78/900, line-height 0.98) + 보조 문구 (20/500), 간격 8, 세로 중앙
- RED 상태: 바탕 `color.signal`, 글자 `color.paper`
- BLACK 상태: 바탕 `color.paper`, 글자 `color.ink`, 하단 2 px 선
- 보조 문구는 상태마다 한 줄 고정:

| 상태 | 보조 문구 | 출처 |
|---|---|---|
| 수업중 · 특강 · 대여중 | `15:00에 끝납니다` | 현재 슬롯/예약 `eH:eM` |
| 쉬는시간 | `14:00 수업 재개` | 다음 `:00` 경계 |
| 시험중 | `시험기간 12.15 – 12.19` | `exams[]` 시작·종료일 |
| 빈강의실 | `15:00부터 수업` | 다음 슬롯 `sH:sM`. 없으면 `오늘 수업 없음` |
| 휴강 | `오늘 휴강입니다` | — |

### 정보 — 형태 A (현재 슬롯·예약 있음)

3행 고정. 라벨열 104 px (x 24–128), 간격 18, 값 x 146부터.

| 행 | 라벨 (20/500) | 값 (28/700) |
|---|---|---|
| 1 | 과목명 | `subj` |
| 2 | 담당교수 | `prof` |
| 3 | 강의시간 | `13:00 – 15:00` |

### 정보 — 형태 B (현재 슬롯 없음 · 빈강의실)

- `다음 수업까지` (20/500) + `1시간 08분` (62/900), 간격 10, 세로 중앙
- 24시간 이상이거나 다음 수업이 없으면 `오늘 일정 없음` (28/700) 한 줄로 대체

### 이전 · 다음 수업 컬럼

두 칸 모두 같은 구조, 요소 간격 7:

1. 태그 칩 — 흑색 바탕, 흰 글자 16/700, 패딩 3(상하)/9(좌우). `이전 수업` / `다음 수업`
2. 시각 `11:00 – 12:50` (24/700)
3. 과목 (20/500)
4. 교수 (16/400)

값이 없으면 칩 아래에 `없음` (24/700) 한 줄만 둔다.

### 푸터

흑색 바탕, 흰 글자 16/500. 좌·중·우 3분할:

| 위치 | 내용 | 예 |
|---|---|---|
| 좌 | 건물·호수·유닛 | `B03 · 301 · U1` |
| 중 | 데이터 버전 · 펌웨어 | `S12 R04 E01 · fw 7` |
| 우 | 배터리 전압 + 아이콘 26×14 | `3.92 V` |

- 전압은 `batt_mV`를 그대로 V로 표기한다. **퍼센트로 바꾸지 않는다** — 방전 곡선이 없어 임의 환산이 된다.
- `CLOCK_STALE`(25 h 이상 TIME 미수신, §5.2)이면 중앙을 `시각 미동기`로 대체한다.

## 문자열 한계

- 과목 **20 B**(UTF-8, 한글 6자) · 교수 **12 B**(한글 4자). 스펙 §5.1의 고정 버퍼 그대로.
- 28 px × 한글 6자 ≈ 200 px, 값 영역 386 px 안에 들어간다. **줄바꿈·말줄임 처리를 설계하지 않는다.**
- 버퍼를 넘긴 문자열은 서버가 이미 잘라 보낸다. 단말은 받은 그대로 그리고 말줄임표를 붙이지 않는다.

## 미결

1. **28 px Bold 한글 자산 추가 여부** — 플래시 여유(앱 3 MB, §6.9)를 보고 dh가 판단한다. 추가가 어려우면 값 행을 20 px로 내리고 그만큼 상태 띠를 키우는 대안을 쓴다. 그 경우 타입 단계에서 28을 뺀다.
2. **건물 코드 표기** — 푸터의 `B03`은 `cfg.bld` u8을 2자리로 쓴 임시안이다. 운영에서 건물을 어떻게 부르는지 정해지면 맞춘다.
3. **유닛 2개 강의실** — 같은 방의 두 단말이 같은 화면을 그린다. 문별로 구분할 필요가 있으면 헤더에 유닛 표기를 올린다.
