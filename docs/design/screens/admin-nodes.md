- 시안: https://claude.ai/artifact/NLQyYEEdt4Rv6Dn7JZZuHi (`노드 상태` 아트보드)
- 소비자: wj → `web/src/views/`
- 전제: `tokens.md` v2 (`admin` 치수 세트) · `components.md`
- 대상: **데스크톱 전용** (`bp.desktop` ≥ 1024px) — `README.md` 규칙

## 목적 · 진입

**장비가 살아 있는지 본다.** 그리고 새 노드를 강의실에 배정한다.

진입: 사이드 메뉴 `노드 상태`. 사이드바 하단의 모뎀Pi 연결 표시를 눌러도 온다.

이 화면은 **설치와 운영의 화면**이다. 시간표를 다루지 않는다.

## 레이아웃 — 블록 셋

서버 엔드포인트가 셋이라 블록도 셋이다. 억지로 합치지 않는다.

```
┌─ 상단 ────────────────────────────────────────────────┐
│ ESP노드 · 모뎀Pi   건물[전체▾] [시각 브로드캐스트] [+ 모뎀Pi 등록] │
└───────────────────────────────────────────────────────┘
┌ 모뎀Pi ─────────────┐┌ 모뎀Pi ─────────────┐
│ ● gonghak-01 공학관 ││ ● sahoe-01 사회관   │   ← 건물당 1대, 가로 나열
│ agent 0.4.1 · 방금  ││ agent 0.4.0 · 14분전│
│ [연결됨] 토큰 재발급 ││ [끊김]  토큰 재발급  │
└─────────────────────┘└─────────────────────┘
┌─ ESP노드 ──────────────────── ☐ 문제 있는 것만 ────────┐
│ 호수│MAC│FW│배터리│신호│버전 S/R/E/I│상태│마지막 수신│작업│
└───────────────────────────────────────────────────────┘
┌─ 등록 대기 ───────────────────────────────────────────┐
│ MAC│모뎀Pi│FW│배터리│신호│처음 발견│마지막 발견│[강의실 배정]│
└───────────────────────────────────────────────────────┘
```

블록 사이 `space.5`. 전체 높이 1120px이라 1440×900에서 `등록 대기`는 스크롤해야 보인다 — 평소에는 비어 있는 블록이라 아래에 두는 것이 맞다.

## 등록 대기가 이 화면의 존재 이유다

노드를 벽에 붙이고 전원을 넣으면 **MAC만 아는 장치**로 여기 뜬다. 관리자가 강의실을 골라 주면 그때부터 그 방의 노드가 된다. **이 블록이 없으면 설치를 할 수 없다.**

- `강의실 배정` → Modal. 건물·호수·`unit`(1 또는 2)을 고른다. `POST /pending/{mac}/provision` (`ProvisionIn{bld, room, unit}`).
- 배정하면 그 행이 사라지고 `ESP노드` 표에 나타난다. 두 블록이 **같은 장치의 두 단계**임을 이동으로 보여준다.
- `처음 발견`과 `마지막 발견`을 나란히 둔다. 둘이 크게 벌어져 있으면 계속 깨어 있다는 뜻이고, 가까우면 방금 켠 것이다.
- 비어 있을 때가 정상이다. EmptyState 문구: "등록을 기다리는 장치가 없습니다."

## 값을 어떻게 보이나

### 배터리 — 퍼센트로 바꾸지 않는다

`batt_mv`를 V로만 바꿔 적는다(`3980` → `3.98 V`). **퍼센트 환산을 하지 않는다** — 리튬 방전 곡선을 모르는 채 환산하면 없는 정밀도를 만들어 낸다.

`low_batt`가 `true`면 그 값을 `room.busy` 틴트 배지로 감싼다. 임계값은 서버가 판단하고 화면은 플래그만 읽는다.

### 신호 — 숫자와 막대를 함께

`rssi`를 `−71 dBm`으로 적고 **옆에 3칸 막대**를 둔다. 막대만으로는 −71과 −88을 가를 수 없고, 숫자만으로는 좋은지 나쁜지가 안 읽힌다. 둘 다 둔다.

막대 칸 수는 화면이 정한다: `≥ −75` 3칸 · `≥ −90` 2칸 · 그 아래 1칸. 색은 쓰지 않고 채워진 칸 수로만 말한다(`text.2` / `line.3`).

### 버전 — 네 개를 한 칸에

`sched_ver` / `resv_ver` / `exam_ver` / `ident_ver`를 `41/12/3/2`로 붙여 적고 헤더를 `버전 S/R/E/I`로 쓴다. 네 열로 펴면 표가 넓어지는데 **평소에 읽는 값이 아니다** — 어긋났을 때만 본다.

### 상태 — `sync_state` 하나로

| 표시 | 뜻 |
|---|---|
| `동기화됨` | 서버가 보낸 것이 다 반영됨 |
| `대기` | 보낸 것이 아직 안 닿음 |
| `응답 없음` · `배터리` | 문제 (`danger` 테두리 배지) |

`clock_stale`·`low_batt`도 여기 배지로 합쳐 보여준다. 한 행에 배지가 둘 이상이면 가장 나쁜 것만 남기고 나머지는 툴팁으로 민다.

⚠ **`sync_state`의 실제 문자열 값을 모른다.** 위 라벨은 화면 쪽 제안이고 wj 확인이 필요하다(미결 1).

## 사용하는 컴포넌트

Table, Badge(상태·배터리), Button(`primary` 배정·등록 / `secondary` 브로드캐스트 / `ghost` 재전송·토큰), Modal(배정, 토큰 재발급 확인), Toast, Checkbox(문제만), Skeleton, EmptyState, Select(건물)

노드 전용 — `components/domain/`:

- **`SignalBars`** — props: `rssi`. 3칸 막대 + 숫자. 위 규칙을 진다
- **`NodeStateBadge`** — props: `syncState` · `clockStale` · `lowBatt`. 셋을 받아 **하나의 배지**로 줄인다

## 데이터 (서버 계약)

| 하는 일 | 엔드포인트 |
|---|---|
| 모뎀Pi 목록 | `GET /api/lora/modems` → `ModemOut{modem_id, agent_ver, modem_fw, last_seen_at, connected}` |
| 모뎀Pi 등록 | `POST /api/lora/modems` (`ModemIn`) → `TokenOut{modem_id, token}` |
| 토큰 재발급 | `POST /api/lora/modems/{modem_id}/token` → `TokenOut` |
| 노드 상태 | `GET /api/lora/status?bld=&room=` → `StatusOut[]` |
| 등록 대기 | `GET /api/lora/pending` → `PendingOut{mac, modem_id, fw, batt_mv, rssi, first_seen_at, last_seen_at}` |
| 강의실 배정 | `POST /api/lora/pending/{mac}/provision` (`ProvisionIn{bld, room, unit}`) → `Enqueued` |
| 시각 브로드캐스트 | `POST /api/lora/time` → `{modems: N}` |
| 재전송 | `POST /api/rooms/{id}/sync` |

`StatusOut`에 화면이 쓰는 값이 **전부 들어 있다.** 새로 만들 서버 필드가 없다.

### 토큰은 한 번만 보인다

`POST /modems`와 `/token`의 응답 `token`은 **그때 한 번만 받는다.** 서버가 다시 알려주지 않는다.

- 발급 직후 Modal에 토큰을 크게 띄우고 `복사` 버튼을 둔다. 닫기 전에 **"이 창을 닫으면 다시 볼 수 없습니다"**를 명시한다.
- 재발급은 확인 Modal을 거친다 — 기존 토큰이 즉시 무효가 되어 **그 모뎀Pi가 끊긴다.** 본문에 그 사실을 적는다.
- 토큰을 표에 두지 않는다. 화면 어디에도 상시 노출하지 않는다.

## 상태

- **로딩**: 각 블록 본문에 Skeleton. 모뎀Pi 카드는 2개분.
- **빈 상태**: 모뎀Pi 0개 — "등록된 모뎀Pi가 없습니다" + `모뎀Pi 등록`. 노드 0개 — "이 건물에 배정된 노드가 없습니다" + 아래 `등록 대기`를 가리키는 문구.
- **에러**: Toast(danger) + 재시도. 이전 표를 지우지 않는다 — 장비 화면에서 빈 표는 "전부 죽었다"로 오독된다.
- **자동 새로고침**: 30초. 관리자가 노드를 켜고 이 화면을 보고 있는 상황이 잦다. 수동 `새로고침`도 둔다.

## 미결

1. **`sync_state` 값 목록** — 실제 문자열을 wj에게 확인. 위 라벨 매핑은 제안이다
2. **`unit` 1/2의 뜻** — 한 강의실에 노드 2대를 붙이는 경우의 표시 방법. `401-1` / `401-2`로 쓸지 한 행에 묶을지
3. **배터리 임계값** — `low_batt` 판정을 서버가 한다고 보고 그렸다. 서버에 임계가 없으면 화면이 정해야 한다
