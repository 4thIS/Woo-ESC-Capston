# 학생 웹 — 강의실 (S10)

- 시안: https://claude.ai/artifact/NLQyYEEdt4Rv6Dn7JZZuHi (`학생 웹` 4장 — 첫 진입 / 강의실 / 이번 주 / 넓은 폭)
- 소비자: wj → `web/src/views/`
- 전제: `tokens.md` v2 (`student` 치수 세트) · `components.md`
- 대상: **모바일 우선.** `bp.mobile` → `bp.tablet` → `bp.desktop` 세 폭 모두에서 동작한다

## 목적 · 진입

학생이 **복도에서 폰으로 "지금 이 강의실 비었나"를 확인한다.** 그게 전부다.

진입은 **별도 도메인을 직접 치고 들어오는 것**이다(로드맵 §5 — QR 폐기, 2026-09-16 팀 결정). 이 한 가지가 화면 설계를 지배한다:

- 학생은 **어느 강의실인지 모르는 상태로** 도착한다. 첫 화면이 강의실 하나일 수 없다.
- 주소가 곧 상태다. 친구에게 링크를 보내면 같은 화면이 열려야 한다.
- 브라우저 뒤로가기가 동작해야 한다. **앱이 아니다.**

관리자 웹과 같은 코드베이스(`web/`)이지만 진입 도메인이 다르고 로그인이 없다.

## 라우트

셋뿐이다. `E`는 `BuildingOut.bld` — 서버에 이미 있는 A~Z 한 글자다.

| 경로 | 화면 | 비고 |
|---|---|---|
| `/{bld}` | 건물의 강의실 목록 | **첫 진입.** `/` 로 오면 건물 선택 후 리다이렉트 |
| `/{bld}/{room}` | 그 강의실 | 공유 가능한 딥링크. `링크 복사` 버튼 |
| `/{bld}/{room}/week` | 이번 주 | 모바일에서만 별도 화면 — 아래 「넓은 폭」 |

예: `esc.wsu.ac.kr/E/401`

- 건물·강의실이 없으면 404 화면 + `/{bld}` 로 돌아가는 링크. 주소를 잘못 친 경우가 흔하다.
- 마지막으로 본 건물과 강의실 2개를 `localStorage`에 남긴다. 다음 방문에 첫 화면 위쪽 `최근 본 강의실`로 뜬다. **로그인 대신 쓰는 장치다.**

## 화면 1 — `/{bld}` 강의실 목록

```
┌ 헤더 58 ────────────────────────┐
│ 우송 ESC            [공학관 ▾]  │
├─────────────────────────────────┤
│ 5곳 이 지금 비어 있어요          │  ← 24px bold
│ 공학관 18개 강의실 · 10:42 기준  │
│                                 │
│ 최근 본 강의실                   │
│ [401호 수업중] [405호 비어있음]  │  ← 48px
│                                 │
│ 공학관 전체       ☑ 빈 강의실만   │
│ ┌─────────────────────────────┐ │
│ │ 401호  수업중 · 캡스톤디자인 ›│ │  ← 56px
│ │        10:00 에 비어요       │ │
│ │ 402호  비어있음           › │ │
│ │        13:00 까지           │ │
│ └─────────────────────────────┘ │
│ ● 문 앞 e-Paper 와 같은 내용     │
└─────────────────────────────────┘
```

- **맨 위는 시간표가 아니라 개수다.** 학생이 원하는 건 "지금 빈 곳"이지 시간표가 아니다. 주간 시간표는 세 번째 화면으로 민다.
- 목록의 각 행은 **호수보다 상태를 먼저 말한다.** 큰 글씨는 호수(식별)이고, 그 옆 줄이 상태와 언제 바뀌는지다.
- 행 높이 56px(터치 하한 48 이상). 전체가 링크다 — `›` 만 누르게 하지 않는다.
- `빈 강의실만` 체크박스는 **기본 켜짐.** 18개를 다 보여주는 것보다 5개를 보여주는 게 목적에 맞는다. 끄면 전체가 보인다.
- 페이지 바탕 `bg.student`(`gray.25`), 카드 `surface`. 관리자 웹의 "흰 바탕 + 헤어라인"을 그대로 쓰면 모바일에서 카드 경계가 사라진다.

## 화면 2 — `/{bld}/{room}` 강의실

```
┌ 헤더 58 ────────────────────────┐
│ ‹   공학관 401호      [링크 복사] │  ← ‹ 는 /{bld} 로 가는 진짜 링크
├─────────────────────────────────┤
│ ┌── 지금 ───────────────────┐   │
│ │ [수업중]                   │   │  ← room.busy 틴트 카드
│ │ 캡스톤디자인                │   │  20px bold
│ │ 박찬우 · 09:00 – 10:00     │   │
│ │ 10:00 에 비어요            │   │  15px bold, danger
│ └───────────────────────────┘   │
│ 오늘          10월 23일 금       │
│ ┌───────────────────────────┐   │
│ │ 09:00 캡스톤디자인 [수업중] │   │  ← 48px
│ │ 10:00 비어있음 — 13:00 까지 │   │
│ └───────────────────────────┘   │
│ [이번 주 전체 보기         ›]    │
└─────────────────────────────────┘
```

- **`지금` 카드가 이 화면의 전부다.** 나머지는 부록이다. 카드 안에서 제일 큰 글자는 과목명이고, 제일 강한 것은 `10:00 에 비어요` — 학생이 알고 싶은 한 줄이다.
- 비어 있을 때는 카드가 `surface` + `line.2`로 바뀌고 라벨이 `비어있음`, 강조 줄이 `13:00 까지 비어요`가 된다. **틴트를 쓰지 않는다**(비어있음은 칠하지 않는다).
- `오늘` 목록은 **빈 구간도 행으로 보여준다.** 수업만 나열하면 언제 비는지를 학생이 계산해야 한다.
- `‹`는 `/{bld}`로 가는 `<a>`다. 브라우저 뒤로가기와 결과가 같아야 한다.
- `링크 복사`는 `navigator.clipboard`로 현재 URL. 성공하면 Toast(`neutral`) "링크를 복사했습니다".

## 화면 3 — `/{bld}/{room}/week` 이번 주

**관리자 페이지2와 같은 격자다 — 요일이 가로, 시간이 세로.** 형태를 맞추는 이유는 같은 시스템을 두 번 배우지 않게 하기 위해서다. 그리고 이 형태에서는 **빈 칸이 곧 비어 있는 시간**이라, 학생이 찾는 것이 따로 표시 없이 읽힌다.

규칙은 관리자와 같고 **눈금만 줄인다.**

| | `bp.mobile` (390) | `bp.tablet` 이상 |
|---|---|---|
| 30분 행 높이 | 24px | 32px |
| 18행 높이 | 432px | 576px |
| 시각 열 | 34px | 40px |
| 하루 열 폭 | 64px | 200px 이상 |
| 블록 내용 | 과목명만 (2줄 줄바꿈 허용) | 유형 라벨 + 과목명 + 시각 |
| 위치 | 별도 화면 | `/{bld}/{room}` 안에 함께 |

범위는 09:00~18:00 18행, 주중 5열. 관리자의 `야간 보기`·`주말 보기` 토글은 두지 않는다 — 학생 화면에 스위치를 늘리지 않고, 해당 슬롯이 있으면 자동으로 편다.

**오늘 열**은 `brand.tint` 바탕 + `brand` 요일 머리로 세우고, 현재 시각에 `brand` 2px 가로선을 긋는다. **여기에 적색을 쓰지 않는다** — 적색은 `사용중` 전용이라 '지금'에 쓰면 두 뜻이 섞인다.

### 겹침 — 관리자와 규칙이 갈린다

**학생 웹은 겹친 `사용중` 블록을 하나로 합친다.**

```
금 10:00–12:00 알고리즘 + 금 11:00–13:00 동아리 대관
  → 관리자: 반씩 나눠 그리고 겹친 구간에 danger 막대
  → 학생  : 「알고리즘 외 1건 · 10:00–13:00」 한 덩어리
```

학생에게 중요한 건 "누가 쓰는지"가 아니라 **"쓰이는지"**다. 겹침을 해결해야 하는 쪽은 관리자이고, 학생은 그 방이 언제 비는지만 알면 된다. 실무적으로도 390px에서 반씩 쪼개면 한 칸이 32px이라 글자가 들어가지 않는다.

합친 블록의 라벨은 **먼저 시작한 것의 이름 + `외 N건`**, 시각은 합집합의 시작~끝이다.

## 넓은 폭 — `bp.tablet` 이상

**화면을 키우는 게 아니라 더 보여준다.** 라우트는 그대로 `/{bld}/{room}` 하나다.

| | `bp.mobile` | `bp.tablet` 이상 |
|---|---|---|
| 강의실 목록 | 별도 화면(`/{bld}`) | **좌측 340px 고정.** 폰에서 뒤로가기로 오가던 것이 한 화면에 |
| 이번 주 | 별도 화면(`/week`) | 우측에 **같은 격자**로 함께. 눈금만 커진다 |
| 다음 비는 시간 | `지금` 카드 안 한 줄 | **별도 카드**로 승격 (`10:00 – 13:00 · 3시간`) |
| `오늘` 목록 | 시각 + 과목 + 배지 | 시각 구간 + 과목 + 교수 + 배지 |

`/week` 라우트는 넓은 폭에서 `/{bld}/{room}`으로 리다이렉트한다 — 이미 그 안에 있다.

**색 값은 폭에 따라 바뀌지 않는다.** 바뀌는 것은 `student` 치수 세트와 배치뿐이다.

## 사용하는 컴포넌트

Select(건물), Checkbox(빈 강의실만), Button(`secondary` 링크 복사), Badge, Toast, EmptyState, Skeleton

학생 웹 전용 — `components/domain/`:

- **`RoomListRow`** — 호수 + 상태 2줄 + `›`. 높이 56px. props: `room` · `state`(busy/free) · `label` · `until`
- **`RoomNowCard`** — `지금` 카드. props: `state` · `subject` · `professor` · `span` · `changeAt`. busy면 `room.busy` 틴트, free면 `surface`
- **`WeekGrid`** — 요일 가로 × 시간 세로 격자. props: `days`(1~7 중 보일 것) · `blocks: { day, top, height, label, extra, type }[]` · `rowHeight`(24 | 32) · `todayIndex` · `nowTop`. 관리자 페이지2의 격자와 **형태는 같고 규칙이 하나 다르다** — 겹친 블록을 합쳐서 받는다(위 §겹침). 합치는 계산은 컴포넌트가 아니라 서버가 한다

Table은 쓰지 않는다. `SlotForm`·`OutboxDot`·`SourceBadge`는 관리자 전용이라 여기 없다.

## 데이터 (서버 계약) — ⚠ 아직 없다

**지금 서버에는 학생 웹이 쓸 API가 없다.** 두 가지가 막는다.

### 1. 인증이 없다

`server/app/domain/router.py`는 `APIRouter(prefix="/api")` 하나이고 **인증 의존성이 붙어 있지 않다.** 지금 상태로 학생 웹이 `/api`를 그대로 쓰면, 화면에 버튼이 없을 뿐 학생도 `PUT /api/rooms/{id}/slots`와 `DELETE`를 부를 수 있다.

학생 웹은 **로그인 없이 읽기만** 해야 하므로 쓰기와 분리된 공개 경로가 필요하다.

### 2. 파생값을 화면이 계산할 수 없다

이 화면이 쓰는 값은 전부 **지금 시각 기준 파생값**이다 — `지금 상태` · `몇 시에 비는지` · `지금 비어있는 곳이 몇 곳인지`. 서버에는 `slots`·`reservations`·`exams` 원본만 있다.

화면이 계산하려면 강의실 18개 × 3종 = **54번 호출**하고 겹침·우선순위(시험 > 예약 > 시간표)를 프론트에서 다시 구현해야 한다. 그 우선순위 규칙은 이미 펌웨어와 서버에 있다 — 세 번째 구현을 만들게 된다.

### 요청할 것

```
GET /api/public/{bld}/rooms
  → [{ room, state, label, subject, professor, until }]   건물의 모든 강의실 현재 상태

GET /api/public/{bld}/{room}
  → { now: {...}, today: [{ from, to, state, subject, professor }],
      week: [{ day, blocks: [{ from, to, label, extra, type }] }] }
```

- 읽기 전용, 인증 없음, 쓰기 경로와 분리
- `state`는 `busy` / `free` 둘뿐 — 화면이 세 종류 원본을 합치지 않는다
- `until`·`from`·`to`는 서버가 계산해 문자열로 준다
- **`week`의 겹친 `사용중` 블록은 서버가 합쳐서 준다** (위 §겹침). 화면이 합치면 모바일·넓은 폭 두 곳에 같은 계산이 생긴다

**이 API 없이는 착수할 수 없다.** wj에게 이슈로 요청한다(건물 단위 조회 이슈 #36과 성격이 다르다 — 그건 관리자용 원본 조회, 이건 학생용 파생 조회다).

## 상태

- **로딩**: 목록 자리에 Skeleton 5행. `지금` 카드 자리에 Skeleton 블록.
- **빈 상태**: `빈 강의실만`이 켜져 있는데 결과가 0이면 "지금은 모든 강의실이 사용 중입니다" + 체크 해제 버튼. 건물에 강의실이 없으면 "등록된 강의실이 없습니다".
- **에러**: 화면 상단 Banner(`danger`) + `다시 시도`. **이전 내용을 지우지 않는다** — 오래된 값이라도 아무것도 없는 것보다 낫고, 그때는 갱신 시각이 오래됐음을 아래 줄이 말한다.
- **갱신**: 화면 하단에 `문 앞 e-Paper 와 같은 내용 · 10:41 갱신`. 데이터가 5분 이상 오래되면 그 줄을 `danger`로 바꾼다.
- **자동 새로고침**: 60초마다. 탭이 백그라운드면 멈춘다(`document.hidden`).

## 미결

1. **도메인** — `esc.wsu.ac.kr`은 예시다. 실제 주소 확정 필요
2. **건물 코드 노출** — URL에 `bld`(`E`) 한 글자를 쓸지 건물 이름(`/공학관`)을 쓸지. 한 글자가 짧지만 학생이 못 읽는다. 서버가 이미 `bld`를 갖고 있어 일단 이것으로 썼다
3. **`/` 첫 진입** — 건물이 여럿일 때 무엇을 기본으로 보일지. `localStorage`에 최근 건물이 있으면 그리로, 없으면 건물 선택 화면
