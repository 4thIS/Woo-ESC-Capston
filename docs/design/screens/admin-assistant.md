# 관리자 — AI 비서 (상단 명령창)

- 시안: [캔버스](https://claude.ai/artifact/JhfVpLroT2reZokrFa5B5g) 페이지 `상단 명령창 흐름` — `Flow`(직접 눌러 보기) · `Step1`~`Step6`(단계별)
- 소비자: wj → `web/src/admin/assistant/` (관리자 셸에 하나. **라우트가 없다**)
- 전제: `tokens.md` v2 (`admin` 치수 세트) · `components.md` · [주간 시간표](admin-schedule.md)(격자 모양을 그대로 쓴다)
- 근거: `docs/specs/2026-11-25-admin-ai-assistant-design.md` §7 · 부록 `docs/plans/2026-11-25-ai-assistant-00-interfaces.md` §4
- 대상: **데스크톱 전용** (`bp.desktop` ≥ 1024px)

## 목적 · 진입

**관리자가 보던 화면을 떠나지 않고 한 문장으로 시간표·일정·시험기간·학생 신청을 바꾸고, 바뀌는 모습을 보고 적용한다.** 모델은 문장을 양식으로 옮기기만 하고, 되묻기·검증·전후 비교는 서버가 한다. 이 창은 그 결과를 보여 주고 [적용]을 받는다.

진입: 사이드 메뉴 맨 위 묶음 **`AI`** 의 **`AI 비서`** 버튼, 또는 키보드 **`Ctrl`+`K`**(macOS `⌘`+`K`). 어느 관리자 화면에서나 같다. **화면을 옮기지 않는다** — 지금 보던 화면 위에 창이 열린다. 건물 관리자·최고 관리자 모두 보인다.

> 처음 초안(대화 열 380px + 기존│수정 두 격자, `/admin/assistant` 별도 화면)을 바꿨다(2026-11-25, wj 시안). 이유: 관리자는 주간 시간표·강의실 설정을 보다가 고칠 일이 생긴다 — 화면을 옮기면 보던 맥락을 잃고, 두 격자를 나란히 두면 1440×900 에서 [적용]이 스크롤 아래로 내려간다.

## 흐름

| 상태 | 창 | 뒤 화면 |
|---|---|---|
| 닫힘 | 없음 | 그대로 |
| **명령창** | 본문 위쪽에 한 줄(56px)이 위에서 내려온다 | `--modal-backdrop` 으로 덮음 |
| **보내는 중** | 한 줄 그대로, 아래 테두리에 진행 줄 | 덮음 |
| **되묻기** | 한 줄 아래에 질문 칸이 붙어 늘어난다 | 덮음 |
| **확인** | 한 줄이 **아래로 펼쳐져** 본문을 거의 다 덮는다 | 덮음 |
| **적용 후** | 다시 한 줄로 접히고 결과를 알린 뒤 닫힌다 | 덮개가 걷히며 새로 불러온 화면 |

- **사이드 메뉴는 덮지 않는다** — `AI 비서` 버튼으로 언제든 닫을 수 있게. 덮개는 본문 영역(사이드 메뉴 오른쪽)만 덮는다.
- 닫기: × 버튼 · `Esc` · 덮개 클릭 · `AI 비서` 버튼 다시 누름. **확인 상태에서 닫으면 미리보기는 적용되지 않는다**(취소와 같다). 대화 기록은 남지 않는다 — 다시 열면 빈 명령창.

## 창의 모양 (모든 상태 공통)

- 위치: 본문 영역 안, 위 `space.4`, 좌우 `space.5`. 폭 = 본문 폭 − 2 × `space.5`.
- 바탕 `surface`, 테두리 `line.2` 1px, 라운드 `radius.lg`. **그림자를 쓰지 않는다**(`tokens.md` 「그림자 토큰은 없다」) — 층은 뒤 덮개(`--modal-backdrop`, Modal 과 같은 `gray.800` `.45`)가 진다.
- 머리 줄(높이 56px, 패딩 0 `space.3` 0 `space.4`): 왼쪽 `assistant` 아이콘(20px, `brand`) · 가운데 내용 · 오른쪽 `Button` `ghost` × (`aria-label="닫기"`).

### 움직임

| 바뀜 | 움직임 | 길이 · 곡선 |
|---|---|---|
| 열림 | 위에서 내려옴(`esc-drop-in`) + 덮개 나타남 | `--dur-base` · `--ease-soft` |
| 한 줄 → 확인 | **높이가 아래로 늘어난다.** 안 내용은 다 늘어날 즈음 나타남(`esc-fade-in`) | `--dur-slow` · `--ease-soft` |
| 확인 → 적용 후 | 높이가 한 줄로 줄어든다 | `--dur-slow` · `--ease-soft` |
| 닫힘 | 위로 올라가며 사라짐 + 덮개 걷힘 | `--dur-base` |

길이·곡선은 `tokens.css` 의 구현 값(`--dur-*`·`--ease-soft`, 다른 화면 전환과 같은 것)이다. `prefers-reduced-motion` 이면 모두 즉시 바뀐다(`base.css` 전역 규칙).

## 명령창 (입력)

- 가운데 내용: 입력칸 — 테두리 없이 머리 줄을 채운다, `font.size.lg`, 최대 300자, 숨은 라벨 `AI 비서에게 말하기`, 자리 글 `한 문장으로 말하세요 — 예: 803 금요일 15~18시 특강`. 오른쪽에 `Button` `primary` `sm` `보내기`.
- 열리면 입력칸에 포커스. 닫히면 포커스를 연 버튼으로 돌려준다.
- **Enter = 보내기**, 한글 조합 중 Enter 는 보내지 않는다. 빈 입력은 보내지 않는다.
- 이 상태의 1차 버튼은 `보내기` 하나다. 확인 상태에서는 `보내기` 가 사라지고 `적용` 이 1차 버튼이 된다 — 화면에 `primary` 는 늘 하나.

## 보내는 중

- 입력칸 자리에 보낸 문장(`text.2`, 한 줄 말줄임) · 오른쪽 `변경 내용을 정리하는 중…`(`font.size.sm`, `text.3`).
- 머리 줄 아래 테두리 자리에 2px 진행 줄 — 바탕 `brand.tint`, 움직이는 막대 `brand`(길이 30%, 왼→오 반복). `role="progressbar"` + `aria-label="변경 내용을 정리하는 중"`.
- 모델이 양식을 만들고 서버가 답할 때까지. 이 동안 새로 보낼 수 없다.

## 되묻기 (`kind: ask`)

머리 줄 아래에 칸이 붙는다(바탕 `sunken`, 위 `line.1` 1px, 패딩 `space.3` `space.4`, 늘어남 `--dur-base`):

- 첫 줄: `AI` (`brand`, `medium`) + 질문(`message`).
- 선택지(`choices`)가 있으면 그 아래 `Button` `secondary` `sm` 줄. 누르면 그 라벨로 다음 턴.
- 없으면 답 입력칸(`Input`, 폭 360px) + `Button` `primary` `답하기` + `Button` `ghost` `요청 취소`.
- 머리 줄에는 처음 보낸 문장이 남는다(`text.2`).

## 확인 (`kind: preview`) — 펼친 창

창이 본문 아래 `space.5` 까지 펼쳐진다. 위에서 아래로:

1. **머리 줄** — 보낸 문장(`text.2`) · 오른쪽 `HH:MM 까지`(`expires_at` KST, `text.3`, `num`) · ×.
2. **본문** — 위 `line.1` 1px, 두 열(왼쪽 340px │ 오른쪽 나머지, 사이 `space.5`), 패딩 `space.2` `space.5` `space.4`. 넘치면 각 열이 따로 스크롤한다.
3. **아래 줄**(높이 64px, 위 `line.1` 1px, 패딩 0 `space.5`) — 왼쪽 `변경 N건 · 겹침 N건`(`text.2`), 오른쪽 `[취소]`(`secondary`) `[적용]`(`primary`). 적용 중이면 `[적용]` 이 `loading`. **막음이 있으면 `[적용]` 비활성.**

### 왼쪽 열 — 무엇이 바뀌나

- 제목 `변경 확인 · {강의실 이름}` (`font.size.lg`, bold). 강의실이 둘 이상이면 `변경 확인 · 강의실 N곳`.
- 요약(`summary`) — 한 줄씩, `font.size.md`.
- **막음**(`blockers`) — 하나라도 있으면 앞에 `적용할 수 없습니다:` 한 줄 + `danger` 글자 목록. `role="alert"`.
- **경고**(`warnings`) — 앞에 `⚠` + `text.1`. 적용은 할 수 있다.
- **안내**(`notices`) — `text.3`.
- **하루 막대** — 바뀌는 날마다 하나(정규 시간표만 바뀌면 바뀌는 요일마다). 바탕 `sunken`, 라운드 `radius.lg`, 패딩 `space.3`:
  - 제목 `11/27(금)` (정규 시간표는 `금요일`) — `font.size.sm`, bold, `text.2`.
  - `기존` 줄과 `수정` 줄 — 왼쪽 라벨(32px, `font.size.xs`, bold, `text.2`) + 가로 막대(바탕 `surface`, `line.1` 1px, `radius.sm`). 막대 범위는 09~18시, 그날 블록이 밖에 있으면 넓힌다. 블록은 격자와 같은 상태 색, 변경은 아래 「변경 표시」 테두리. 같은 시각에 겹치면 줄을 위아래로 나눈다. 겹친 구간은 `danger` 3px 세로 막대.
  - 아래 눈금 `09` `12` `15` `18` (`font.size.xs`, `text.3`, `num`).
  - 날이 셋보다 많으면 셋만 그리고 `외 N일` — 나머지는 오른쪽 격자에서 본다.
- 마지막 줄 `적용하면 문 앞 화면으로 보냅니다. HH:MM 까지 적용하지 않으면 이 확인은 사라집니다.` (`font.size.sm`, `text.3`).
- 강의실이 둘 이상이면 제목 아래에 **강의실 표**(`Table`: 강의실 · 추가 · 삭제 · 수정, 숫자 오른쪽 정렬). 행을 누르면 그 강의실로 하루 막대와 오른쪽 격자가 바뀐다(선택 행 `brand.tint`).

### 오른쪽 열 — 주 전체

- 제목 줄: `11/23~11/29 주`(정규 시간표만 바뀌면 `매주 시간표`, bold, `num`) · 오른쪽 `SegmentedControl` **`기존 | 수정`**(기본 `수정`). 바뀌는 주가 여럿이면 제목 양옆 `◀` `▶`.
- 그 아래 주간 격자 하나(세로 스크롤).

### 격자

[주간 시간표](admin-schedule.md)의 격자와 **같은 모양**(30분 행 44px, 09~18시 기본, 필요하면 야간·주말 자동). 다른 점:

- 셀·블록을 누를 수 없다(편집 없음). 전송 점(OutboxDot)은 없다.
- `기존` 과 `수정` 은 **같은 시각 범위**를 쓴다 — 전환해도 행이 움직이지 않는다.
- 정규 시간표만 바뀐 경우 요일 헤더에 날짜를 적지 않는다(`월` `화` …).

### 변경 표시

블록 바탕은 **원래 상태 색 그대로**(`room.busy` / `room.free` — 상태 색 규칙을 깨지 않는다). 변경은 **테두리 2px + 머리 태그(기호 + 글자)** 로만 표시한다. 색만으로 읽히지 않게 기호와 글자를 함께 쓴다.

| 변경 | 나오는 쪽 | 테두리 | 태그 | 그 밖 |
|---|---|---|---|---|
| 추가 | 수정 | `diff.add.line` 2px 실선 | `+ 추가` — 바탕 `diff.add.fill`, 글자 `diff.add.text` | — |
| 삭제 | 기존 | `diff.remove.line` 2px 점선 | `− 삭제` — 바탕 `diff.remove.fill`, 글자 `diff.remove.text` | 과목명 취소선 |
| 수정 | 양쪽 | `diff.change.line` 2px 실선 | `~ 수정` — 바탕 `diff.change.fill`, 글자 `diff.change.text` | `title` 에 `바뀐 칸: 시작 · 이름` |

- 시험기간이 바뀐 날은 요일 헤더 아래 `시험기간` 띠 옆에 같은 태그를 붙인다.
- 연속 교시 묶음 안에서 일부 교시만 바뀌면 묶음 전체를 `~ 수정` 으로 표시한다.

## 적용 후

- 펼친 창이 한 줄로 접힌다. 머리 줄: 체크 아이콘(`diff.add.text`) · `적용했습니다. 문 앞 화면으로 보내는 중입니다.` · 오른쪽 `OutboxDot` + `문 앞 반영 중`.
  - `acked` → `문 앞 반영 완료`, **3초 뒤 창이 닫힌다.**
  - `failed` → `일부 전송 실패 — 강의실 설정에서 재전송` (`danger`). **닫히지 않는다** — ×로 닫는다.
  - 30초 동안 따라간다(기존 전송 추적과 같은 규칙). 그 뒤에도 끝나지 않으면 `문 앞 반영 중` 인 채로 3초 뒤 닫힌다.
- 뒤 화면(주간 시간표 등)은 다시 불러온다.

## 오류

| 경우 | 표시 |
|---|---|
| 모델이 양식을 못 만듦 · 서버가 이해 못 함(`kind: error`) | 되묻기 칸 자리에 `danger` 글자 한 줄(서버 `message`) + 입력칸이 다시 열린다 |
| 다른 관리자가 그사이 바꿈(409 `stale`) | 확인 내용을 새 미리보기로 바꾸고 왼쪽 열 맨 위 `Banner` `확인하는 동안 다른 변경이 있었습니다. 바뀐 내용으로 다시 확인해 주세요.` |
| 만료(410) | 창을 한 줄로 접고 `확인 화면이 만료되었습니다. 다시 말씀해 주세요.` (`danger`) + 입력칸 |
| 모델 판이 바뀜(409 `schema_version`) | `AI 모델이 새 판으로 바뀌었습니다. 새로고침해 주세요.` + `Button` `secondary` `새로고침` |
| 요청이 너무 잦음(429) | `잠시 뒤 다시 보내 주세요.` |
| 그 밖 | 서버 `message` 그대로 |

## 모델 상태

처음 열 때 모델이 이 PC 에 없으면, 명령창 입력칸은 비활성이고 되묻기 칸 자리에 상태가 선다.

| 상태 | 표시 |
|---|---|
| 안내 받는 중 | `Skeleton` 한 줄 |
| 준비 중 (`enabled:false`) | `AI 비서를 준비하고 있습니다. 모델이 배포되면 여기서 쓸 수 있습니다.` (`text.2`) |
| 받기 전 | 두 줄(`이 PC 에서 AI 모델을 돌립니다. 문장은 학교 서버로만 갑니다.` / `처음 한 번 약 N GB 를 받습니다. 받는 동안 다른 화면을 써도 됩니다.`) + `Button` `primary` `AI 모델 받기 (약 N GB)`. N = 안내 `files` 크기 합(소수 한 자리) |
| 받는 중 | `ProgressBar` (`label` = `AI 모델 받는 중`) + 아래 `N.N / M.M GB` (`num`) + `Button` `ghost` `취소`. 창을 닫아도 계속 받는다 — 다시 열면 이어서 보인다 |
| 불러오는 중 | `Skeleton` + `모델을 불러오는 중…` |
| 저장 공간 부족 | `danger` `저장 공간이 부족합니다 (필요 N GB, 남은 M GB). 브라우저 저장 공간을 비운 뒤 다시 확인해 주세요.` + `다시 확인` |
| 이 PC 에서 못 씀 | 이유 한 줄(아래) |
| 실패 | 오류 문구 + `Button` `secondary` `다시 시도` |

이 PC 에서 못 쓰는 이유:
- WebGPU 없음: `이 브라우저는 WebGPU 를 지원하지 않아 AI 비서를 쓸 수 없습니다. 최신 Chrome·Edge 를 쓰세요.`
- 그래픽 장치 없음: `이 PC 의 그래픽 장치로는 AI 모델을 돌릴 수 없습니다.`
- 메모리 부족: `이 PC 의 메모리가 부족해 AI 모델을 돌릴 수 없습니다.`
- 저장소 없음: `이 브라우저는 모델을 저장할 수 없습니다(사생활 보호 모드 등).`

## 변경 기록

명령창 상태(입력칸이 비어 있을 때)에서 머리 줄 오른쪽에 `Button` `ghost` `sm` `변경 기록`. 누르면 아래 칸이 펼쳐져 `Table`: `적용 시각`(KST `YYYY-MM-DD HH:MM`) · `관리자` · `요청`(관리자 문장) · `변경`(요약, 줄마다). 최신 50건, 칸 최대 높이 400px 스크롤. 빈 상태 `AI 비서로 적용한 변경이 아직 없습니다`. 입력을 시작하면 칸이 접힌다.

## 사이드 메뉴 버튼

`SidebarNav` 맨 위 묶음 `AI` 의 항목 하나 — **링크가 아니라 버튼**이다(`components.md` SidebarNav `action`).

- 모양은 다른 항목과 같다(높이 32px, `radius.md`) + 바탕 `surface`, 테두리 `line.2` 1px — 화면을 옮기지 않는 항목임을 면으로 구별한다. 오른쪽 끝에 단축키 표시 `Ctrl K` (macOS `⌘K`, `font.size.xs`, `text.3`, 테두리 `line.3` `radius.sm`).
- 창이 열려 있으면 활성 모양(바탕 `brand.tint`, 글자·테두리 `brand`), `aria-expanded="true"`.

## 접근성

- 창은 `role="dialog"` + `aria-modal="true"` + `aria-label="AI 비서"`. 열려 있는 동안 포커스는 창 안에서 돈다(사이드 메뉴의 `AI 비서` 버튼은 예외로 닿는다).
- 되묻기 질문·적용 결과는 `aria-live="polite"`, 막음 목록은 `role="alert"`.
- 격자 블록은 이름에 변경을 넣는다: `금 15:00–18:00 예약 · 특강 알고리즘 특강, 추가`.
- 키보드: 입력칸 → 보내기 → (되묻기) 선택·답 → 확인 열 → `[취소]` `[적용]` 순.

## 미결

- 대화 기록 보관 기간 안내 문구(서버 180일)를 화면에 둘지 — 1단계는 두지 않는다.
- 모델 크기: 0단계 실험의 E2B q4f16_1 변환본은 약 2.6 GB 다(#172). 안내 문구는 숫자를 고정하지 않고 안내 `files` 합으로 적는다.
