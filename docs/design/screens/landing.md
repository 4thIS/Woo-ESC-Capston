# 메인 페이지 — `/` (로그인 전)

- 시안: [캔버스](https://claude.ai/artifact/NLQyYEEdt4Rv6Dn7JZZuHi) `Landing`(390) · `Wide-Landing`(1280) — **아직 없다**(미결 1)
- 소비자: wj → `web/src/student/views/`
- 전제: `tokens.md` v2 (`student` 치수 세트) · `components.md`
- 관련: [auth.md](auth.md)(로그인 탭) · [student-room.md](student-room.md)(`/` 건물 선택 · 로그인 벽)
- 대상: 학생 웹. 모바일 우선, `bp.mobile` → `bp.tablet` → `bp.desktop` 세 폭 모두

## 목적 · 진입

주소를 치고 들어온 사람이 **여기가 어느 학교의 무슨 서비스인지** 먼저 보고, 로그인으로 넘어가는 화면이다. 지금까지는 `/` 에 로그인하지 않고 들어오면 바로 로그인 벽이 섰다 — 처음 온 사람에게는 이 서비스가 무엇인지 말해 주는 화면이 없었다.

| 누가 `/` 로 오나 | 보이는 것 |
|---|---|
| 로그인하지 않음 | **이 화면** |
| 로그인함 | 지금 그대로 건물 선택(또는 바로 건물로) — [student-room.md](student-room.md) 「`/` — 건물 선택」 |

- **`/` 에서만 이 화면을 띄운다.** `/E/401` 같은 딥링크로 비로그인 진입하면 지금처럼 로그인 벽(`LoginGate`)이다 — 그쪽은 "어느 건물인지"를 말하는 역할이 따로 있다(student-room.md §로그인 벽).
- 관리자도 이 화면을 거쳐 로그인한다. 메인 페이지에는 학생·관리자를 가르는 버튼을 두지 않고, **로그인 화면 맨 위 `학생 | 관리자` 탭**에서 고른다([auth.md](auth.md) 「`/login`」).

## 레이아웃 — 폰

```
┌ / ──────────────────────────────┐
│ ESC                    [로그인] │  ← 헤더 58px. 로그인 = secondary sm
├─────────────────────────────────┤
│                                 │
│ 우송대학교                       │  ← school_name   font.size.xl 700 text.1
│ 강의실 시간표와 예약을            │
│ 문 앞 전자종이와 웹에서 한 번에.   │  ← 소개 한 문장  font.size.lg 400 text.2
│                                 │
│ ─────────────────────────────── │  ← line.1
│ 지금 빈 강의실                   │  ← 할 수 있는 일 셋, 각 행 48px
│ 이번 주 시간표                   │     font.size.md 500 text.1
│ 예약 신청·승인                   │
│ ─────────────────────────────── │
│                                 │
│ [         로그인          ]      │  ← primary md, 전체 폭 (이 화면의 brand 채움 하나)
│ 처음이신가요? 가입 신청            │  ← 가입 신청 = brand 글자 링크
└─────────────────────────────────┘
```

- 페이지 바탕 `bg.student`, 본문 좌우 여백 `space.4`, 블록 사이 `space.5`.
- 헤더는 학생 웹의 다른 화면과 같은 높이·선(`StudentHeader`)이다. 왼쪽 `ESC`(`font.size.md` 700)는 `/` 로 가는 링크, 오른쪽 `로그인` 은 **`secondary` `sm`** 이다 — 화면을 내리지 않아도 로그인으로 갈 길. 채움 brand 는 본문 아래 버튼 하나뿐이다.
- 할 수 있는 일 셋은 **링크가 아니다.** 눌러도 갈 곳이 로그인 뒤다. 아이콘·번호를 붙이지 않는다 — 순서가 있는 목록이 아니다(가입 단계 `StepList` 와 헷갈리지 않게).
- `로그인` → `/login`(학생 탭이 기본). `가입 신청` → `/signup`.

## 레이아웃 — 넓은 폭 (`bp.tablet` 이상)

```
┌ ESC ─────────────────────────────────────────────── [로그인] ┐
│                                                              │
│                 ┌──────── 최대 640px ────────┐               │
│                 │ 우송대학교                  │               │
│                 │ 강의실 시간표와 예약을 …     │               │
│                 │ ─────────────────────────  │               │
│                 │ 지금 빈 강의실              │               │
│                 │ 이번 주 시간표              │               │
│                 │ 예약 신청·승인              │               │
│                 │ ─────────────────────────  │               │
│                 │ [        로그인         ]  │  ← 최대 400px │
│                 │ 처음이신가요? 가입 신청      │               │
│                 └────────────────────────────┘               │
└──────────────────────────────────────────────────────────────┘
```

- 헤더는 전체 폭, 본문은 **640px 을 넘기지 않게 가운데** — 건물 선택 화면(`Student-Wide-Home`)과 같은 틀이다. 세로는 위에서 `space.7` 내려 시작한다(세로 가운데 아님 — 로그인 후 건물 선택과 제목 위치가 같아야 화면이 바뀌어도 눈이 따라간다).
- `로그인` 버튼은 칸 폭을 다 채우지 않고 **최대 400px** — 로그인 폼 폭(auth.md 「넓은 폭」)과 같다.
- 할 수 있는 일 셋은 로그인 화면 왼쪽 소개 칸(auth.md 「넓은 폭」)과 **같은 문구**다. 같은 세 줄을 두 곳에 두는 것이므로 바꾸면 둘 다 바꾼다.

## 학교 이름 — 공개 API 하나가 필요하다

로그인 전 화면은 지금까지 **학교를 몰랐다**(auth.md — 그래서 `ESC` 만 썼다). 학교 조회 `GET /api/schools` 는 관리자 전용이다. 이 화면만은 학교 이름을 보여야 하므로 **로그인 없이 부르는 엔드포인트 하나를 서버에 추가**한다(additive, wj 이슈).

| 하는 일 | 엔드포인트 | 응답 |
|---|---|---|
| 학교 이름 | `GET /api/public/school` (인증 없음) | `{name}` |

- **이름 한 칸만** 준다. `net_id` · `email_domain` 은 내보내지 않는다 — 가입 화면이 도메인을 적지 않는 것과 같은 이유다(auth.md 「202가 아닌 응답」).
- 메인Pi 한 대가 학교 하나를 맡는다는 전제다(로드맵 토폴로지). `schools` 에 행이 둘 이상일 때 어느 것을 줄지는 서버 결정이다(미결 2).
- **이 화면만 부른다.** `/login` · `/signup` 등 나머지 인증 화면은 지금처럼 `ESC` 다 — 그 화면들은 학교 이름이 없어도 할 일을 한다.
- 로그인 뒤에는 이 값을 쓰지 않는다. 로그인 뒤 화면은 로그인 응답의 `school_name` 을 쓴다(student-room.md §내 정보 줄).

## 상태

| 상태 | 화면 |
|---|---|
| 학교 이름 응답 전 | 이름 자리에 `Skeleton` 한 줄(`font.size.xl` 높이, 폭 160px). 소개·버튼은 바로 보인다 — 로그인은 이 응답을 기다릴 이유가 없다 |
| 학교 이름 실패·빈 값 | **이름 줄만 감춘다.** 에러를 띄우지 않는다. 소개 문장이 첫 줄이 된다 |
| 로그인 상태로 `/` | 이 화면을 그리지 않고 건물 선택으로 |

- 학교 이름은 **한 번 받고 다시 부르지 않는다**(폴링 없음). 바뀔 일이 거의 없는 값이다.

## 사용하는 컴포넌트

`StudentHeader`, Button(`primary` 로그인 · `secondary` `sm` 헤더 로그인), Skeleton
