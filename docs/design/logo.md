# 로고 · 파비콘

- 시안: https://claude.ai/artifact/SQ1D7DS78Ke8hzpft9t6tn — 판 `C 확정안` 의 **로고 ②**. 같은 캔버스에 후보 A~L 12개가 있다
- 원본 파일: [`assets/logo/`](assets/logo/) — `esc-logo.svg`(로고) · `esc-logo-dark.svg`(어두운 바탕용 로고) · `favicon.svg`(파비콘, 다크 탭 대응) · `favicon-16.svg`(16px 전용)
- 소비자: wj → 학생 웹 · 관리자 웹의 브랜드 자리, `web/index.html` · `web/admin.html` 의 아이콘

## 무엇인가

**로고는 `ESC` 세 글자를 막대로 짠 글자 로고**이고, **파비콘은 그 첫 글자 `E`** 다.

막대 세 줄은 시간표의 세 줄이다. 가운데 줄이 "지금"이고, 그래서 `E` 와 `S` 의 가운데 줄은 `brand` 파랑이다. 주간 격자의 현재 시각 선과 오늘 목록의 현재 행에 쓰는 바로 그 색이다(`tokens.md` — "지금"을 가리키는 표시는 brand). `C` 는 글자 전체가 파랑이다.

글꼴을 쓰지 않는다. 막대(사각형)만으로 그려서 Pretendard 가 없는 곳에서도 똑같이 보이고, 글자를 윤곽선으로 바꿀 필요가 없다.

## 짜임 — 로고 (132 × 48)

세 글자가 같은 격자를 쓴다. 단위는 SVG `viewBox` 값이다.

| 항목 | 값 |
|---|---|
| 글자 높이 | 48 |
| 막대 두께 | 9 (가로 · 세로 모두) |
| 세 줄의 위치 | 위 `y 0` · 가운데 `y 19.5` · 아래 `y 39` |
| 글자 폭 | `E` 40 · `S` 40 · `C` 36 |
| 글자 사이 | 8 |
| 전체 | 132 × 48 (가로 : 세로 = 2.75 : 1) |
| 떠 있는 간격 | 4 — 파란 가운데 줄이 먹 막대와 떨어지는 거리 |

| 글자 | 먹(`text.1`) | 파랑(`brand`) |
|---|---|---|
| `E` | 세로 막대 `0,0 9×48` · 위 `0,0 40×9` · 아래 `0,39 40×9` | 가운데 `13,19.5 27×9` — 세로 막대에서 4 떨어진다 |
| `S` | 위 `48,0 40×9` · 왼쪽 위 세로 `48,0 9×15.5` · 오른쪽 아래 세로 `79,32.5 9×15.5` · 아래 `48,39 40×9` | 가운데 `48,19.5 40×9` — 위아래 세로 막대에서 4씩 떨어진다 |
| `C` | — | 위 `96,0 36×9` · 세로 `96,0 9×48` · 아래 `96,39 36×9` |

좌표는 `x,y 폭×높이`. 원본은 [`assets/logo/esc-logo.svg`](assets/logo/esc-logo.svg) 이고, 위 표와 파일이 다르면 파일을 고치지 말고 이 표를 먼저 고치는 PR 을 연다.

## 짜임 — 파비콘 (64 × 64)

로고의 `E` 를 정사각 칸에 놓은 것이다. 정사각에 맞춰 폭만 44 로 넓혔다.

| 막대 | 값 | 색 |
|---|---|---|
| 세로 | `10,8 9×48` | `text.1` |
| 위 · 아래 | `10,8 44×9` · `10,47 44×9` | `text.1` |
| 가운데 | `23,27.5 31×9` — 세로 막대에서 4 떨어진다 | `brand` |

**16px 은 따로 그린다** — 64 격자를 16 으로 줄이면 막대가 2.25px 이 되어 번진다. 16 격자에 맞춘 그림([`favicon-16.svg`](assets/logo/favicon-16.svg)): 막대 3 · 간격 2, 세로 `2,2 3×13` · 위 `2,2 12×3` · 가운데 `7,7 7×3`(파랑) · 아래 `2,12 12×3`.

## 색 — 라이트 모드 (기본)

웹 화면은 지금 전부 라이트 모드다. 로고 · 파비콘의 기본 판이다.

| 자리 | 값 | 대비 |
|---|---|---|
| 먹 | `text.1` #262626 | 흰 바탕 15.13 |
| 파랑 | `brand` #0B5ED7 | 흰 바탕 5.84 |

- 파일: 로고 `esc-logo.svg`, 파비콘 `favicon.svg`(밝은 색) · `favicon-16.svg`.
- 바탕: 흰색 · `surface` · `bg` · `sunken` 까지. 그보다 어두운 회색(`gray.300`~`gray.600`) 바탕에는 로고를 두지 않는다.
- 색을 바꾸지 않는다 — 한 색(먹만, 파랑만)으로 칠하거나, 파랑 자리를 옮기지 않는다.

## 다크 모드

막대 · 좌표 · 파랑 자리는 라이트 모드와 같고 **두 색만 바뀐다.**

| 자리 | 값 | 대비 |
|---|---|---|
| 먹 | #E3E3E3 (`gray.200`) | #262626 위 11.79 · #1C1C1C 위 13.28 · 브라우저 어두운 탭 #35363A 위 9.40 |
| 파랑 | #5B9BF0 | #262626 위 5.33 · #1C1C1C 위 6.00 · #35363A 위 4.25 |

`brand` #0B5ED7 을 어두운 바탕에 그대로 두면 #262626 위 2.59 로 막대가 꺼져 보인다. 그래서 밝힌 파랑을 따로 둔다. 파랑과 먹의 사이도 2.21 이라 가운데 줄이 먹과 섞이지 않는다.

| 대상 | 파일 | 언제 다크로 바뀌나 |
|---|---|---|
| 로고 | `esc-logo-dark.svg` | **놓이는 바탕이 어두울 때.** 시스템 설정(`prefers-color-scheme`)이 아니라 그 자리의 바탕색으로 고른다 |
| 파비콘 | `favicon.svg` 하나 (탭 아이콘으로만) | **브라우저 · 시스템이 다크일 때** — 파일 안의 `@media (prefers-color-scheme: dark)` 가 스스로 바꾼다. 탭 줄이 시스템을 따라 어두워지기 때문이다 |
| `favicon.ico` · `apple-touch-icon.png` | 라이트 판만 | 바뀌지 않는다. `.ico` 는 SVG 를 못 읽는 옛 브라우저용이고, 홈 화면 아이콘은 흰 판 위에 그려 어디서나 보인다 |

- **지금 웹 화면에서는 로고가 항상 라이트 판이다.** 웹에 다크 모드가 없어서(`tokens.md` — 범위 밖) 시스템이 다크여도 페이지 바탕은 흰색이다. 이때 로고까지 시스템을 따라 바꾸면 흰 바탕에 #E3E3E3(대비 1.28)이 올라가 사라진다. 그래서 로고는 `<picture media="(prefers-color-scheme: dark)">` 로 고르지 않는다.
- 어두운 판을 쓰는 자리: 발표 자료 · 어두운 GitHub README · 어두운 사진 위 등 **바탕이 어둡다고 확실한 곳.** 바탕: #262626(`gray.800`)보다 어둡다.
- **웹에 다크 모드가 들어오면** 그 다크 화면의 헤더 · 인증 왼쪽 소개 등 「쓰는 자리」의 모든 로고를 어두운 판으로 바꾼다. 바꾸는 신호는 페이지 테마(예: `<html data-theme="dark">`)와 같아야 한다 — 페이지 바탕과 로고가 다른 신호를 따르면 둘이 어긋난다. 그때 #E3E3E3 · #5B9BF0 을 다크 토큰으로 정하는 `tokens.md` PR 을 먼저 연다.
- 두 값은 **지금은 로고 · 파비콘 전용**이고 웹 토큰이 아니다(#5B9BF0 은 팔레트에 없다). 화면 UI 에 가져다 쓰지 않는다.
- 다크 모드에서도 그림자 · 테두리 · 빛남을 더하지 않는다. 바탕 판(예: 흰 둥근 칸)을 깔아 라이트 판을 억지로 쓰지 않는다 — 어두운 판을 쓴다.

## 쓰는 자리

화면 스펙에서 **브랜드 자리에 적힌 `ESC` 는 이 로고**를 뜻한다. 글자 `ESC` 를 굵게 적던 자리를 로고 그림으로 바꾼다. 문장 안의 `ESC`(바닥글 `ESC — 전자종이 · LoRa …`, 문서 제목)는 글자로 둔다.

| 자리 | 로고 높이 | 스펙 |
|---|---|---|
| 메인 페이지 헤더 왼쪽 (넓은 화면 72 · 폰 · 태블릿 58) | 20px | [landing.md](screens/landing.md) |
| 인증 화면 왼쪽 소개 맨 위 (`/` 로 가는 링크) | 20px | [auth.md](screens/auth.md) |
| 폰 로그인 띠 · 폼 위 작은 `‹ ESC` | 16px | [auth.md](screens/auth.md) |
| 학생 웹 로그인 벽 헤더 · 로그인 전 헤더 | 20px | [student-room.md](screens/student-room.md) |
| 관리자 사이드바 머리 — `school_name` 이 없는 옛 세션의 32px 로고 칸 | `favicon-16.svg` 를 정확히 2배(32px). 장식이라 `alt=""` | [components.md](components.md) SidebarNav |

- 로그인 뒤 헤더는 지금처럼 `school_name` 만 적는다 — 로고를 붙이지 않는다(학교 이름 규칙은 그대로).
- 링크일 때(인증 왼쪽 등) 로고 `<img>` 를 감싼 `<a>` 에 포커스 링을 둔다. 로고 칸 높이가 터치 하한(48)보다 작으면 링크 칸을 48 로 키운다.
- 대체 텍스트: `<img alt="ESC">`. 인라인 SVG 면 `role="img" aria-label="ESC"`. 링크라면 링크 이름이 `ESC` 로 읽히면 된다.
- **관리자 사이드바의 `E` 는 로고가 아니라 학교 칸이다.** 평소 이 칸은 학교 이름 첫 글자(`우`)이고 옆에 학교 이름(`우송대학교`)이 붙는다. 옛 세션이면 그 자리가 `E` + `ESC` 가 될 뿐이라, 아래 「하지 않는 것」의 'E 를 또 붙이지 않는다'에 걸리지 않는다. 옆에 글자가 있으므로 `E` 그림은 `alt=""` 다.
- **화면 안에 `E` 를 그릴 때는 `favicon-16.svg` 를 16 의 정수배(16 · 32 · 48)로 쓴다.** `favicon.svg` 는 쓰지 않는다 — 아래 「파일」 참고.

## 파일 — wj 구현

| 파일 | 만드는 법 | 연결 |
|---|---|---|
| `esc-logo.svg` | [`assets/logo/esc-logo.svg`](assets/logo/esc-logo.svg) 그대로 | 화면에서 `<img>` 또는 인라인 SVG |
| `esc-logo-dark.svg` | [`assets/logo/esc-logo-dark.svg`](assets/logo/esc-logo-dark.svg) 그대로 | 지금은 화면에 연결하지 않는다 — 다크 모드가 들어오면 페이지 테마 신호로 바꾼다(「다크 모드」) |
| `favicon.svg` | [`assets/logo/favicon.svg`](assets/logo/favicon.svg) 그대로 | `<link rel="icon" href="/favicon.svg" type="image/svg+xml">` |
| `favicon.ico` | 16 = `favicon-16.svg`, 32 = `favicon.svg` 의 밝은 색을 래스터로 | `<link rel="icon" href="/favicon.ico" sizes="32x32">` — SVG 를 못 읽는 브라우저용 |
| `apple-touch-icon.png` | 180 × 180, 흰 바탕(#FFFFFF)을 꽉 채우고 `favicon.svg` 를 그대로 키운다(밝은 색). 모서리는 iOS 가 깎는다 | `<link rel="apple-touch-icon" href="/apple-touch-icon.png">` |

- `web/index.html` · `web/admin.html` 둘 다 같은 아이콘을 쓴다. 지금의 `<link rel="icon" href="data:,">` 를 위 세 줄로 바꾼다.
- **`favicon.svg` 는 탭 아이콘 전용이다 — 화면 안 `<img>` · CSS `background` 로 쓰지 않는다.** 파일 안의 `prefers-color-scheme: dark` 는 `<img>` 로 넣어도 시스템 설정을 따른다. 그래서 시스템이 다크면 흰 화면 위에서 먹이 #E3E3E3 으로 바뀌어(흰 바탕 대비 1.28) 사라진다. 지금 웹은 시스템이 다크여도 페이지가 흰색이다(「다크 모드」). 색이 바뀌지 않는 `favicon-16.svg` 를 쓴다(#136 에서 확인).
- 탭 제목(`<title>`)은 이 스펙 범위 밖이다 — 지금 값(`강의실 게시` · `강의실 게시 관리자`)을 그대로 둔다.

## 하지 않는 것

- 로고를 늘리거나 눌러 비율을 바꾸지 않는다. 막대 두께를 바꾸지 않는다.
- 로고 옆에 글자 `ESC` 나 파비콘 `E` 를 또 붙이지 않는다 — `E` 가 두 번 읽힌다.
- 로고를 상태 표시(배지 · 점 · 차트) 안에 넣지 않는다. 파랑이 "지금" 표시와 섞인다.
- 로고 뒤에 적색(`room.busy`)을 깔지 않는다.
- 밝은 판을 어두운 바탕에, 어두운 판을 밝은 바탕에 두지 않는다. 판 둘 사이의 중간 색을 새로 만들지 않는다.
