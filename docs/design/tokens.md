# 디자인 토큰 v1

- 시안: ⚠ 미정 — 확정되면 이 줄에 링크
- 소비자: wj → `web/src/styles/` (관리자 웹 S4 · 학생 웹 S10 공통)
- 상태: **초안.** ⚠ 표시된 값은 시안 확정 전 제안값이다. 이름·구조는 확정, 값은 바뀔 수 있다.

토큰 이름은 그대로 CSS 변수가 된다: `color.status.busy` → `--color-status-busy`.

## 원칙 — 색은 세 값뿐이다

단말 e-Paper는 흑·백·적 3색이 **패널의 물리적 한계**다. 웹에는 그 한계가 없지만, **웹도 같은 세 값만 쓴다.** 브라우저가 쓸 수 있다는 이유로 색을 늘리지 않는다.

1. **값은 셋뿐이다** — 흑 하나, 백 하나, 적 하나. **회색은 없다.** 옅은 회색 선도, 중간 회색 보조 텍스트도 없다.
2. **위계는 크기 · 굵기 · 면적 · 반전으로 만든다.** `screens/terminal-epaper.md`가 쓴 방법 그대로다.
3. **적색은 아껴 쓴다.** 용도는 셋뿐이다: 강의실이 **사용중**인 상태 · **파괴적 동작**(삭제·에러) · **포커스 링**.
4. 세 값은 `screens/terminal-epaper.md`의 시안 값을 승계한다.
5. 대비비는 전부 WCAG 2.1 상대휘도로 **계산한 실측값**이다.

> **왜 웹까지 묶나** — 관리자가 웹에서 바꾼 것이 복도의 e-Paper에 그대로 나타나는 시스템이다. 두 화면이 다른 색 언어를 쓰면 같은 강의실의 같은 상태가 다른 것처럼 보인다.

## 색

| 토큰 | 값 | 용도 |
|---|---|---|
| `color.ink` | `#111111` | 글자 · 선 · 반전 바탕. e-Paper `ink` 그대로 |
| `color.paper` | `#F7F6F3` | 모든 바탕. e-Paper `paper`(`#ECEBE5`)와 같은 웜 계열 |
| `color.signal` | `#C8102E` | 적색. 위 원칙 3의 세 용도에만 |

**이 셋이 전부다.** `ink.60`, `surface`, `border` 같은 파생 회색을 만들지 않는다.

### 역할 별칭

wj가 쓰는 이름. 값은 위 셋 중 하나를 가리킬 뿐 새 값을 만들지 않는다.

| 토큰 | = | 비고 |
|---|---|---|
| `color.bg` | `paper` | 페이지 배경 |
| `color.surface` | `paper` | **카드도 같은 바탕이다.** 구분은 배경색이 아니라 `ink` 1px 테두리가 한다 |
| `color.text` | `ink` | 본문 |
| `color.text.muted` | `ink` | **보조 텍스트도 같은 흑이다.** 구분은 크기·굵기가 한다 (아래 표) |
| `color.border` | `ink` | 모든 선. 굵기는 `border.thin`/`border.thick` |
| `color.primary` | `ink` | 주 버튼 — 흑 채움 + 백 글자 (반전) |
| `color.danger` | `signal` | 삭제 버튼 · 에러 |
| `color.focus` | `signal` | 포커스 링 (`outline: 2px solid; outline-offset: 2px`) |

### 조합 규칙

| 바탕 | 쓸 수 있는 글자색 | 대비 |
|---|---|---|
| `paper` | `ink` | 17.47 ✓ |
| `paper` | `signal` | 5.44 ✓ |
| `ink` (반전) | `paper` | 17.47 ✓ |
| `signal` (상태 띠) | `paper` **만** | 5.44 ✓ |

**적색 바탕에 흑 글자를 쓰지 않는다** — 3.21로 4.5:1에 미달한다. 적색 위는 백 글자 하나뿐이다. e-Paper의 "RED 상태: 바탕 `signal`, 글자 `paper`" 규칙과 같다.

## 회색이 필요하다고 느끼는 자리

회색이 없으므로 아래 수단으로 푼다. **이 표가 이 문서의 핵심이다.**

| 자리 | 회색 대신 |
|---|---|
| 보조 텍스트 · 라벨 | 같은 `ink`, `font.size.sm` + `weight.regular` (본문은 `md` + `medium`) |
| 캡션 · 메타 정보 | 같은 `ink`, `font.size.xs` + `weight.regular` |
| 표 구분선 | `ink` 1px. **단 선을 덜 긋는다** — 아래 주 참고 |
| 폼 요소 테두리 | `ink` 1px |
| 카드 · 모달 경계 | `ink` 1px 테두리 (배경색 차이 아님) |
| 비활성 (disabled) | `opacity: .4` |
| hover | `opacity: .85` |
| 빈 셀 · 빈 상태 | 칠하지 않는다. `paper` 그대로 두고 `—` 한 글자 |
| outbox 전송 단계 | 채움 정도 `○ ◐ ●` (아래) |
| 선택된 행·셀 | 반전 (`ink` 채움 + `paper` 글자) |

**`opacity`는 색이 아니라 상태다.** 세 값 외에 쓸 수 있는 유일한 수단이고, 용도는 `disabled`와 `hover` 둘뿐이다. 회색이 필요한 자리에 `opacity`를 끼워 넣어 회색을 되살리지 않는다. (`opacity: .4`의 실효 대비는 2.59라 본문에 쓸 수 없다 — 비활성 표시 전용이다.)

> **선을 덜 긋는다** — 관리자 시간표는 7열 × 여러 행이다. 모든 경계에 `ink` 1px을 그으면 그리드가 새까매진다. 옅은 회색 선으로 도망가는 대신, **실제 경계에만 선을 긋고 나머지는 여백(`space`)으로 나눈다.** 요일 구분과 교시 구분에는 선을 긋고, 셀과 셀 사이는 2px 여백으로 띄운다. 구체적 배치는 `screens/admin-schedule.md`에서 정한다.

## 강의실 상태

e-Paper `layout` 1~8의 RED / BLACK 이분법 그대로. **상태 색은 2개뿐이다.**

| 토큰 | = | e-Paper | 해당 SlotType | 대비(백 글자) |
|---|---|---|---|---|
| `color.status.busy` | `signal` | RED (layout 1·5·6·7) | `CLASS`(1) · `EXAM`(2) · `SPECIAL`(5) · `RENTAL`(6) | 5.44 |
| `color.status.free` | `ink` | BLACK (layout 2·3·4·8) | `CANCELLED`(3) · `EMPTY`(4) · 쉬는시간 · 설정 대기 | 17.47 |

**수업중·시험중·특강·대여중에 서로 다른 색을 주지 않는다.** 네 상태는 전부 `status.busy` 하나다.

왜 그런가 — 이 넷을 색으로 나누려면 같은 적색 계열 안에서 갈라야 하는데, 계산해 보면 서로의 대비가 1.02~1.88이다. 즉 **나눠도 나뉘지 않는다.**

**구분은 라벨 텍스트가 전담한다.** 배지에는 상태명을 반드시 쓴다(`수업중` / `시험중` / `특강` / `대여중`). 색칠된 점·칸만으로 상태를 표현하는 UI는 금지한다.

## outbox 전송 상태

셀 우상단 점 하나. 색이 아니라 **채움 정도**로 단계를 읽는다. 크기 8px, `radius.full`.

| 상태 | 표시 | 색 |
|---|---|---|
| `queued` | `○` 테두리만 (1px) | `ink` |
| `dispatched` | `◐` 반 채움 | `ink` |
| `acked` | `●` 꽉 채움 | `ink` |
| `failed` | `●` 꽉 채움 + 느낌표 | `signal` |
| `cancelled` | `○` 테두리만 + 사선 | `ink`, `opacity: .4` |

`failed` 만 적색이다 — 적색의 세 용도 중 "파괴적 동작·에러"에 해당한다. `cancelled` 는 상위 작업에 밀려 취소된 것이라 비활성으로 죽인다. 상태값은 `OutboxOut.state` 다섯 가지 전부이고, 컴포넌트 규격은 `components.md` 의 OutboxDot 에 있다.

## 성공 · 경고 알림

Toast에 색을 입히지 않는다. 바탕 `paper`, 테두리 `ink` 1px, 글자 `ink`. **에러 Toast만** 왼쪽에 `signal` 3px 띠를 세운다. 성공과 경고는 문구로 구분한다("저장했습니다" / "확인이 필요합니다").

## 타이포

색이 하나뿐이므로 **크기와 굵기가 위계를 전부 진다.** 이 스케일이 곧 정보 구조다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `font.family` | `"Pretendard Variable", Pretendard, system-ui, -apple-system, sans-serif` | |
| `font.family.mono` | `"D2Coding", ui-monospace, monospace` | 시각 · 호수 · MAC 등 자릿수 맞출 곳 |
| `font.size.xs` | 12px | 캡션 · 메타 · 배지 |
| `font.size.sm` | 14px | 보조 텍스트 · 표 본문 |
| `font.size.md` | 16px | 본문 |
| `font.size.lg` | 20px | 카드 제목 |
| `font.size.xl` | 28px | 화면 제목 |
| `font.weight.regular` | 400 | 보조 · 캡션 |
| `font.weight.medium` | 500 | 본문 |
| `font.weight.bold` | 700 | 제목 · 강조 · 상태명 |
| `line.tight` | 1.25 | 제목 · 배지 |
| `line.normal` | 1.5 | 본문 |

같은 크기에서 400과 700의 차이를 적극적으로 쓴다. 중간 굵기(500)는 본문 전용이다.

⚠ Pretendard는 웹폰트다. 메인Pi가 오프라인일 수 있으므로 **CDN이 아니라 `web/src/assets/`에 self-host**한다. 서브셋 범위는 wj와 협의.

## 간격 · 라운드 · 보더

| 토큰 | 값 |
|---|---|
| `space.1` … `space.7` | 4 / 8 / 12 / 16 / 24 / 32 / 48 px |
| `radius.sm` | 4px — 배지 · 입력 |
| `radius.md` | 8px — 버튼 · 카드 |
| `radius.lg` | 12px — 모달 |
| `radius.full` | 999px — outbox 점 |
| `border.thin` | 1px |
| `border.thick` | 2px — 포커스 링 · 선택된 셀 |

**그림자 토큰은 없다.** 그림자는 회색 반투명이라 세 값 규율 밖이다. 띄워야 할 것(모달)은 배경을 `ink` `opacity: .4`로 덮어 구분한다.

간격이 회색 선을 대신하므로, `space`는 장식이 아니라 **구조를 나누는 주 수단**이다.

## 접근성

README의 최소 기준 3개:

1. **텍스트 대비 4.5:1** — 값이 셋뿐이라 가능한 조합이 넷이고, 넷 다 통과한다(위 조합 규칙 표). 미달 조합은 `ink` on `signal`(3.21) 하나이고 금지로 명시했다.
2. **포커스 링 토큰 1개** — `color.focus` 하나.
3. **색만으로 구분하지 않기** — 색이 둘(흑·적)뿐이라 애초에 색으로 구분할 수 없다. 배지의 라벨 텍스트가 구분을 전담하고, outbox는 채움 정도로 단계를 표현한다.

색약 사용자에게도 이 팔레트는 명도 차이로만 읽힌다 — 색 구분에 의존하는 정보가 없다.

## 미결 (시안에서 확정할 것)

1. **시안 링크** — 문서 최상단
2. **`paper` 값** — `#F7F6F3`로 제안했으나, e-Paper 실물(`#ECEBE5`)에 더 붙일지 시안에서 결정
3. **상태 아이콘 도입 여부** — 라벨 텍스트가 이미 구분을 하고 있어 필수는 아니다
4. **Pretendard 서브셋 범위** — wj와 협의 (self-host 전제)
5. **선을 긋는 자리** — 관리자 시간표에서 어디에 선을 긋고 어디를 여백으로 둘지. `screens/admin-schedule.md`(mh-03)에서 정한다
